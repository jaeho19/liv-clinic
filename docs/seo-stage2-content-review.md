# LIV SEO·GEO 2단계 콘텐츠 검토

작업일: 2026-09-09. 대상: 울쎄라·써마지·실리프팅·의료진 4페이지와 해당 페이지의 11개 언어 원본.

가격, VAT, 판매 옵션, 샷·라인 수는 이번 작업에서 제외했다. 이 문서는 저장소의 검토용 자료이며 공개 페이지가 아니다. 의료진 검토자·검토일은 제공받지 않아 새로 표시하지 않았다.

- [Amiri 등, MFU-V 체계적 문헌고찰·메타분석](https://pubmed.ncbi.nlm.nih.gov/39540440/), DOI `10.1093/asj/sjae228`, Aesthetic Surgery Journal 2025;45(3):NP86–NP94. 2024 저작권 표기와 2025 권호 발행을 구분한다.

**공개 미반영 검토 문안:** “MFU-V 연구를 종합한 문헌고찰에서 연구자가 일정 수준의 심미 개선을 평가한 비율은 89%였습니다. 이는 여러 연구의 결과로, 개별 환자의 개선 정도나 LIV의 시술 성과를 뜻하지 않습니다. 연구 설계와 만족도 응답 기준의 차이가 있어 결과 해석에 주의가 필요합니다.”

통계는 의료진이 장비 세대, 적용 부위, 평가 시점과 한계를 검토한 뒤 게재한다. 논문의 통계를 울쎄라피 프라임만의 임상 결과로 확대하지 않는다.

## 운영자 확인과 3단계 인계

- 신사역 4번 출구 도보 안내 시간: 1분/3분 중 임의 선택하지 않았다. 이번 네 페이지 외의 위치·다른 시술 안내는 확인된 시간으로 후속 통일한다.
- 울쎄라·써마지 실제 담당자와 국내 자격, 정품 인증 병원 표기의 근거, 통증 조절·병합 시술 간격 등 기존 운영 문구를 확인한다.
- 의료진 한국어 JSON-LD의 김수영 학력은 한양대학교, 본문은 고려대학교로 서로 다르다. 학력은 이번에 변경하지 않았다. 운영자 확인 후 3단계에서 같은 원본을 사용하도록 정리한다.
- 새 schema, canonical·hreflang·robots·sitemap·날짜 정책은 이번에 추가·변경하지 않았다. 울쎄라 본문에서 제거한 유일성 주장이 기존 시술 schema에 남지 않도록 해당 설명과 benefit 원본만 최소 조정했다.
- 기존 hydration 오류, 모바일 플로팅 CTA와 본문의 겹침, `/icon.svg` 오류는 3단계 기술 점검 대상으로 남긴다.
- 가격 관련 검토는 사용자의 업데이트 후 진행한다. 운영 배포·commit·push·merge·상담 접수·문자·이메일·운영 DB 쓰기는 수행하지 않았다.
