## A. 계정이 필요한 작업 (P0에서 남은 것)

### A1. Search Console 404 목록 내보내기
구글이 아직 찾아가는 옛 주소 221개를 새 주소로 연결(301)하려면 목록이 필요하다. Chrome 확장으로는 표를 추출할 수 없었다.

1. https://search.google.com/search-console 접속 → 속성 `https://liv-clinic.net/` 선택
2. 왼쪽 메뉴 **색인 생성 → 페이지**
3. 아래 표에서 **"찾을 수 없음(404)"** 행 클릭
4. 오른쪽 위 **내보내기 → CSV 다운로드**
5. 파일 이름을 `gsc-404.csv`로 바꿔 `docs/05-handoff/p1-inputs/`에 저장

같은 방법으로 **"발견됨 – 현재 색인되지 않음"(144)**과 **"크롤됨 – 현재 색인되지 않음"(72)**도 내보내 주면(`gsc-discovered.csv`, `gsc-crawled.csv`) 어떤 외국어 페이지가 탈락했는지 정확히 볼 수 있다.

### A3. Bing Webmaster Tools 등록
ChatGPT 검색·DuckDuckGo·Bing이 Bing 색인을 쓴다. Search Console에서 가져오기만 하면 된다.

1. https://www.bing.com/webmasters 접속 → Microsoft 계정으로 로그인(없으면 만들기)
2. **"Import from Google Search Console"(GSC에서 가져오기)** → 구글 계정(jaeho19@gmail.com) 인증 → `https://liv-clinic.net/` 선택 → Import
3. 가져오기가 안 되면 **Add site manually** → 인증 방법 **HTML Meta Tag** 선택 → `<meta name="msvalidate.01" content="…">`의 content 값을 복사해 답변에 적기 (코드에 넣어 드림)
