# 1층 모니터 영상 3편 추가 설계

**작성**: 2026-09-19 | **매체**: 리브성형외과 건물 1층 공용 모니터 | **상태**: 설계 확정 (2026-09-19) — 구현 계획 작성 단계

기존 〈리프팅 시티〉(6분, 완성·검수 통과)는 그대로 두고 3편을 추가한다. 총 4편 16분 루프.

---

## 1. 왜 바꾸는가

〈리프팅 시티〉는 **"우리 병원에 이런 기계가 있다"**를 정리한 영상이다. 문제는 그 문장을 강남
성형외과 대부분이 똑같이 할 수 있다는 것이다. 울쎄라·써마지·덴서티는 리브만 가진 장비가 아니다.

제작 방식도 평평했다. 12개 장면이 전부 같은 6/8/8/4/4 리듬이고, 배경은 항상 블러 처리된 정지
플레이트였으며, 장비는 카드 안에 작게 들어가 있었다.

### 데이터가 가리키는 차별점

| 근거 | 수치 | 출처 |
| --- | --- | --- |
| 네이버 후기 237건 빈출 단어 | **원장 53% · 친절 49% · 상담 36%** | `liv-naver-reviews.json`, `docs/03-analysis/homepage-review-benchmark.html` |
| 경쟁 병원 고평점 후기 공통 표현 | "공장형과 비교 불가", "시술 시간이 길다", **"원장님이 직접"** | `docs/03-analysis/platform-review-research.analysis.md` |
| 리브 후기 237건 중 압토스 언급 | **1건** | 위와 동일 |

손님은 이미 리브를 **사람이 좋은 병원**으로 인식하는데, 홍보는 기계로 하고 있었다. 그리고 가장
밀어야 할 압토스는 인지가 사실상 0이다.

**축을 옮긴다: "무엇이 있는가" → "누가, 무엇을, 어떻게 하는가"**

### 리브만 쓸 수 있는 문장

김수영 대표원장은 조지아 APTOS 본사에서 Professional Course를 수료했고(`KR0062025`,
발급자 G./M./C. Sulamanidze MD), 학회 연단에서 발표한다. 그 현장 사진을 전부 보유하고 있다.
이건 경쟁 병원이 복사할 수 없다.

**실물과 개념도를 분리한다.** 제품의 생김새는 실물 사진(A07)으로 보여주고, 조직 안에서
일어나는 일은 렌더러에서 직접 그린 개념도로 설명한다. 개념도 구간에는 화면 구석에 "개념도"를
표기해 실촬영으로 오인되지 않게 한다.

절차 애니메이션을 Higgsfield로 만들지 않는 이유: 의료기기 형태를 AI에 맡기면 실물과 다른 것을
그려낼 위험이 있고, 직접 그리면 단계별 타이밍을 정확히 통제할 수 있다. 얼굴은 사진이 아니라
**선화(line art)** 로 그린다 — 기존 `lifting/thread-hero.png`는 AI 생성 얼굴이라 쓰지 않는다.

병원이 홈페이지에 이미 공개한 분류(`ko.json > sections.concerns.cards`)를 **그대로** 쓴다.
새로 지어내지 않는다.

| 순서 | 고민 | 상담 방향(병원 공개 표기) |

원장님 확인 결과 **안면거상 상담과 지방재배치 상담은 실제로 진행하지 않으므로 제외**한다.
홈페이지 `sections.concerns.cards`의 `fundamental`·`underEye` 카드가 미진행 시술을 안내하고
있다는 뜻이므로, 홈페이지 쪽 정정은 이 영상 작업과 별개로 처리해야 한다(§4 하단).

### 그대로 쓰는 것 (전부 사실)

- 인증 사실: KFDA 의료기기 4등급 정식 허가 · CE · ISO 13485 · FDA MDSAP
- 사용 범위: 100개국 이상 사용
- 기전 설명: 히알루론산을 나노·서브마이크로·마이크로로 캡슐화해 단계적으로 방출하는 구조
- 원장 자격: APTOS Professional Course 수료, `KR0062025`, 발급자 3인
- 라인업 3종과 적용 부위
- 병원 공개 고민 분류 5종

전후 비교, 효과 보장, 수치화된 개선, 타 병원 비교, 환자 후기·체험담, **연예인·인플루언서 등장**은
4편 전체에 넣지 않는다.
이 설계는 의료광고 심의 완료를 뜻하지 않는다.

### 이 작업 밖에서 처리할 것 (영상 기획 중 발견)

홈페이지 `sections.concerns.cards`에 **실제로 진행하지 않는 시술 2건**이 상담 항목으로 올라가
있다 — `fundamental`("근본적인 처짐 개선 / 안면거상 상담"), `underEye`("눈 밑 그늘과 지친 인상 /
지방재배치 상담"). 원장님이 2026-09-19에 미진행으로 확인했다. 영상에서는 뺐지만 홈페이지는
그대로이므로 별도 정정이 필요하다. 4개 로케일(ko/en/ja/zh) 동시 수정 대상이다.

## 5. 시각 언어 — 1편에서 무엇을 바꾸는가

| | 1편 (기존) | 2~4편 (신규) |
| --- | --- | --- |
| 리듬 | 전 장면 30초 고정, 6/8/8/4/4 | 블록 길이 12~50초 가변 |
| 대상 크기 | 카드 안의 작은 사진 | 화면을 채우는 매크로·전면 |
| 움직임 | 블러 배경의 느린 줌 | 절차 애니메이션(직접 그림) + 실사 확대 |
| 증거 | 장비 이름 | 인증서 번호·본사 현장·연단 사진 |
| 숫자 | 없음 | 100개국 · 4등급 · KR0062025를 큰 타이포로 |
| 전환 | 0.4초 디졸브 일변도 | 하드컷 · 와이프 · 마스크 혼용 |

### 유지하는 것 (1편과 동일)

- 규격: 1080×1920 / 30fps CFR / H.264 yuv420p / 무음 / faststart
- 고정 크롬: 상단 로고 + "리브성형외과", 하단 "이 건물 4층" 로즈 필 + 02-797-2773 — **전 구간**
- 팔레트 `#b4988d` / `#6d4e42` / `#f6f6f6` / `#575756`, Pretendard, 안전여백 72px
- 마지막 12초 QR 고정, 최종 프레임에서 재스캔 검증
- 렌더러 `output/lifting-city/edit/render_video.py` 구조와 병렬 렌더 파이프라인 재사용

### 신규 렌더러 모듈

1. `thread_anim.py` — 실 곡선 + 돌기 생성, 삽입·걸림·고정 3단계 파라미터 애니메이션
2. `particle_anim.py` — HA 캡슐 3크기 단계 확산
3. `face_diagram.py` — 얼굴 선화와 부위 하이라이트 (②편 라인업, ④편 고민 지도 공용)
