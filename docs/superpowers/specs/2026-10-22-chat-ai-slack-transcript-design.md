# Slack 손님 방에 AI 답 전문 + 대화가 멈추면 요약 1개 — 설계서

- 날짜: 2026-10-22
- 요청: 사용자(원장님 대신) — 운영 시험(`CHAT_AI=test`) 도중 "AI 응대로 어떻게 답했는지가 적혀 있는데, 실제로 AI가 어떻게 적었는지도 보이면 좋겠다. 매번 알려주기보다 맨 마지막에 무엇을 묻고 어떻게 답했는지 요약 하나만, 실제 AI 답은 채팅창에서 계속 보이게."
- 결정(같은 날): 요약 시점 = **대화가 멈췄을 때**, AI 답 모양 = **한국어만**, 요약은 **AI가 새로 쓰고 실패하면 차례별 요지로 대신**, 나머지는 아래 설계대로("이대로 진행").
- 바꾸는 것: 스펙 2026-10-02 `chat-ai-first-response` §4.11의 "`AI 응대` 요지 한 줄(답 전체는 관리자 화면에서 본다)"과 제안형 스펙 2026-10-12 §4.6의 요지 아래 `> 제안:` 줄. 직원 알림은 핵심 한 줄만이라는 10/2 원칙([staff-notice-minimal-text])은 **알림 막대**에 그대로 적용하고, AI 답 자체는 이제 대화 내용으로 본다.

## 1. 방에 보이는 것 (손님 글 한 차례)

```
🇬🇧 ○○ 손님   울쎄라 시술 비용은 얼마인가요?  > 원문: How much is Ulthera?   ← 지금과 같다
💬 AI 응대     (손님에게 실제로 나간 답의 한국어 번역 — 전문)                    ← 바뀜
🗓 가예약 / 🙋 직원 확인 필요 막대                                                 ← 지금과 같다(있을 때만)
```

- `AI 응대` 글은 **손님에게 나간 답 전체의 한국어 번역**이다. 멘션도 막대도 없다. 지금의 요지 한 줄, `> 안내한 금액:` 줄, `> 제안:` 줄은 올리지 않는다.
- **금액 안전장치**: 이 답에 가격 줄을 썼고(`usedRows`), 원문의 금액(쉼표를 뺀 4자리 이상 숫자)이 번역문에 하나라도 없으면, 번역문 아래에 프로그램이 만든 정확한 줄 `> 안내한 금액: …`(지금의 `priceQuoteKo`)을 붙인다. 번역이 금액을 바꿔도 방에서 바로 보인다. 날짜·인원·연락처는 파란 막대(프로그램이 만든 한국어)에 정확히 있으므로 따로 보지 않는다.
- **번역 실패**(실패·시간 초과·건너뜀)면 손님에게 나간 글을 그대로 올리고 끝에 `_(번역 실패 — 손님에게 나간 글 그대로)_`를 붙인다. 가격 줄을 썼으면 위의 정확한 줄도 붙인다.
- 한국어로 문의한 손님(답이 이미 한국어)은 번역하지 않고 그대로 올린다.
- 순서: 지금은 Slack 게시와 한국어 번역을 동시에 돌린다. 바꾼 뒤에는 **번역을 먼저 끝내고** 그 결과로 `AI 응대` 글 → 가예약 → 직원 확인 필요 → 연락처 알림 순으로 올린다(번역 시간 한도 5초 — `CHAT_TRANSLATION_TIMEOUT_MS`, 함수 한도 60초 안).
- 관리자 화면 저장은 지금과 같다(번역이 성공하면 `chat_messages.original_text`를 한국어로 바꾼다 — 같은 번역을 한 번만 부른다).
- 매 차례의 요지(`staff_note_ko`)는 계속 만들고 `chat_ai_turns`에 남긴다(주간 점검 내보내기와 요약 실패 때 쓴다). 방에는 올리지 않는다.
- AI가 답하지 못한 차례(접수 안내로 대신 · 대화당 한도)의 빨간 막대는 지금과 같다.

## 2. 대화가 멈추면 요약 1개

- **언제**: 그 대화에 아무 글도 **10분** 동안 오가지 않았고(`chat_sessions.last_message_at` ≤ 지금 − 10분), 지난 요약 뒤에 AI가 답한 차례(`chat_ai_turns.outcome = 'sent'`)가 하나 이상 있을 때. 3분마다 도는 운영 작업(`chat-ops` → `POST /api/chat/ops`)이 본다 — 실제로는 멈춘 지 10~13분 뒤에 올라간다.
- **밤·주말에도** 돈다: AI는 영업시간 밖에도 답하므로, 요약 단계는 영업시간 확인 **앞에서** 돈다(확대 알림·'오늘 연락할 손님'은 지금처럼 영업시간 안에서만).
- **대상에서 빼는 것**: 보관(완료)되었거나 닫힌 대화, 마지막 글이 24시간보다 오래된 대화(배포 직후 옛 대화를 한꺼번에 요약하지 않게), 방도 스레드도 없는 대화(요약은 #해외문의에 따로 올리지 않는다).
- **어디까지 요약했는지**: 새 칸 `chat_sessions.ai_summary_at`(마이그레이션 045). 요약할 때 이 칸을 그 대화의 `last_message_at`으로 **조건부 UPDATE로 선점**한다(읽은 값이 그대로일 때만 — '오늘 연락할 손님'의 `followup_digest_at`과 같은 방식). 크론이 겹쳐도 두 번 올리지 않는다. 선점 뒤 게시가 실패하면 다시 시도하지 않는다(그 구간 요약은 빠진다 — 실제 답은 방에 다 있다).
- **요약할 구간**: 지난 `ai_summary_at` 뒤(없으면 처음부터) ~ 이번 `last_message_at`까지의 글. 손님 글은 한국어 번역(`translated_text`, 없으면 원문), AI 글과 직원 글은 한국어(`original_text`), 자동 안내·시스템 글은 뺀다.
- 손님이 다시 쓰면 다음에 멈출 때 **그 뒤 구간만** 요약 1개를 더 올린다.
- **모양**(멘션 없음, `AI 응대` 이름표):
  ```
  📝 *AI 응대 요약* · 10:43~10:50 · 손님 글 7개
  • 물은 것: 울쎄라 가격, 10/27→10/28 예약 변경, 추가 할인, 임신 중 시술, 휴진일 방문
  • 답한 것: 부위별 가격과 5% 안내, 10/28 11시 가예약(2명), 할인은 직원이 확인한다고 안내, 임신 중엔 권하지 않음, 29일 휴진 안내
  • 직원이 할 일: 가예약 확정 연락, 추가 할인 답, 임신 문의 회신        ← 있을 때만
  ```
- **만드는 법**: AI(`gpt-6-sol`, 같은 키·같은 호출 함수 `callChatAi`)에 그 구간을 주고 JSON `{"asked": "...", "answered": "...", "todo": "..."}`(각 한 줄, 한국어, todo는 없으면 빈 칸)로 받는다. 금액·날짜는 대화에 있는 그대로만 쓰게 하고 새 약속을 만들지 않게 지시한다(요약은 직원만 본다). 시간 한도 20초, 한 번 실행에 최대 3대화를 함께 돌린다(함수 한도 60초). 비용은 한 번에 1~2센트.
- **실패하면**(호출 실패·JSON 깨짐·빈 칸): 그 구간 AI 차례들의 요지(`staff_note_ko`)를 `• ` 목록으로 올리고 머리줄 끝에 `· 자동 요약 실패 — 차례별 요지`를 붙인다. 요지도 없으면 머리줄만 올린다.
- **스위치**: `CHAT_AI_SUMMARY=off`면 요약 단계를 건너뛴다(긴급 정지, 기본은 켜짐). AI가 꺼져 있으면(`CHAT_AI` 비어 있음) 새 AI 차례가 없으므로 저절로 아무것도 하지 않는다.

## 3. 데이터

- 마이그레이션 `045_chat_ai_summary.sql`: `chat_sessions.ai_summary_at TIMESTAMPTZ NULL` 한 칸 + 설명. 추가만 한다(043·044와 같다). 운영 적용 스크립트 `scripts/_db/run-045.mjs` · 검증 `verify-045.mjs`(043·044와 같은 꼴: 기본 dry-run, `--apply`일 때만 COMMIT).

## 5. 시험

- 단위 시험: 한국어 전문 본문, 금액 비교(같음 · 빠짐 · 156만 같은 다른 표기 · 쉼표), 번역 실패 표시, 한국어 손님; 번역 먼저 → 게시 순서와 번역 결과 공유; 요약 대상 고르기(10분 · 24시간 · 보관 · 방 없음 · AI 차례 없음 · 지난 요약 뒤), 조건부 선점(두 번째는 0행), 구간 글 고르기(자동·시스템 제외), AI 요약 파싱 · 실패 대신 · 빈 요지, 스위치 off, ops 라우트가 영업시간 밖에도 요약을 부름.
- 운영 시험(`CHAT_AI=test`, 승인 뒤): `ai-test-…` 문의에서 방에 한국어 전문이 보이는지, 10~13분 뒤 요약 1개가 오는지, 다시 쓰고 멈추면 두 번째 요약이 그 뒤 구간만 담는지.

## 6. 하지 않는 것

- 관리자 화면 · 손님 화면 · 직원 답 번역본(`번역본 · 복사용`)은 바꾸지 않는다.
- #해외문의 피드 줄은 늘리지 않는다(요약은 방에만).
- 요약에 멘션을 넣지 않는다.
- 직원이 쓴 글만 오간 구간은 요약하지 않는다(AI 차례가 없으면 대상이 아니다).
