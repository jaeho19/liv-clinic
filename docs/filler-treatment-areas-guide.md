# 필러 시술 부위 인터랙티브 이미지 가이드

디자이너와 프론트엔드 개발자를 위한 필러 시술 부위 하이라이트 영역 가이드입니다.

---

## 1. 좌표 시스템 개요

### 기본 설정
- **ViewBox**: `0 0 100 100` (퍼센트 기반 좌표 시스템)
- **이미지 비율**: 520 x 650 px (가로:세로 ≈ 0.8:1)
- **preserveAspectRatio**: `none` (이미지와 1:1 매핑)

### 좌표 해석
```
cx, cy: 중심점 좌표 (0-100 범위, 퍼센트로 해석)
rx, ry: 타원의 가로/세로 반지름
r: 원의 반지름
rotate: 회전 각도 (도 단위)
```

### 예시
```javascript
{
  type: 'ellipse',
  cx: 50,      // 가로 중앙 (50%)
  cy: 13,      // 상단에서 13% 아래
  rx: 10,      // 가로 반지름 10%
  ry: 3,       // 세로 반지름 3%
}
```

## 2. 시술 부위별 해부학적 기준 및 좌표

### ① 이마 (Forehead) - 이마 주름 개선

**해부학적 기준**:
- **위치**: 전두근(Frontalis muscle) 중앙부
- **시술 지점**: 미간~헤어라인 사이 1/3 지점의 수평 주름 라인
- **주사 깊이**: 진피층 또는 피하층

**표시 범위**:
- 이마 전체가 아닌, 주름 중심부의 좁은 가로 영역만 표시
- 주름 라인 폭(2-3cm)에 해당하는 영역

**좌표**:
```javascript
{
  id: 1,
  category: 'wrinkle',
  color: '#D4A5A5',  // 분홍색 (주름 개선 카테고리)
  coords: {
    type: 'ellipse',
    cx: 50,     // 얼굴 정중앙
    cy: 13,     // 이마 상단 (헤어라인 아래)
    rx: 10,     // 주름 폭
    ry: 3,      // 주름 두께
  },
}
```

### ② 관자놀이 (Temple) - 볼륨 손실 복원

**해부학적 기준**:
- **위치**: 측두와(Temporal fossa), 눈꼬리 외측 상방 약 2cm
- **시술 지점**: 함몰된 중심부 1-2포인트
- **주사 깊이**: 근막 아래 깊은 층

**표시 범위**:
- 관자놀이 함몰 중심부의 작은 원형 영역
- 양쪽 대칭 표시 필수

**좌표**:
```javascript
{
  id: 2,
  category: 'volume',
  color: '#A89080',  // 베이지색 (볼륨 카테고리)
  coords: [
    { type: 'circle', cx: 21, cy: 25, r: 4.5 },  // 왼쪽 관자놀이
    { type: 'circle', cx: 79, cy: 25, r: 4.5 },  // 오른쪽 관자놀이
  ],
}
```

---

### ③ 코 (Nose) - 콧대/코끝 성형

**해부학적 기준**:
- **위치**: 비근(Nasal bridge 시작점) ~ 비첨(Nasal tip)
- **시술 지점**: 콧대 라인을 따라 3-4포인트 선상 주입
- **주사 깊이**: 골막 위 또는 피하층

**표시 범위**:
- 콧대 중앙 라인만 (좁고 세로로 길게)
- 코 전체가 아닌 시술 라인에 집중

**좌표**:
```javascript
{
  id: 3,
  category: 'contour',
  color: '#6D5A4D',  // 갈색 (윤곽 카테고리)
  coords: {
    type: 'ellipse',
    cx: 50,     // 코 정중앙
    cy: 38,     // 콧대 중간 높이
    rx: 3,      // 콧대 폭 (좁게)
    ry: 7,      // 콧대 길이 (길게)
  },
}
```

---

### ④ 앞광대 (Anterior Cheekbone) - 광대뼈 볼륨

**해부학적 기준**:
- **위치**: 관골(Zygomatic bone) 전면, 눈 아래 약 2cm
- **시술 지점**: 광대 정점(최고점) 1-2포인트
- **주사 깊이**: 골막 위 깊은 층

**표시 범위**:
- 광대뼈 정점 주변의 작은 원형 영역
- 광대 전체가 아닌 볼륨 주입 지점만

**좌표**:
```javascript
{
  id: 4,
  category: 'volume',
  color: '#A89080',
  coords: [
    { type: 'circle', cx: 35, cy: 40, r: 4.5 },  // 왼쪽 광대
    { type: 'circle', cx: 65, cy: 40, r: 4.5 },  // 오른쪽 광대
  ],
}
```

### ⑤ 팔자주름 (Nasolabial Fold) - 팔자주름 개선

**해부학적 기준**:
- **위치**: 비순구(코 옆 ~ 입꼬리까지 이어지는 주름)
- **시술 지점**: 주름 라인 아래 3-4포인트 (상단~중간)
- **주사 깊이**: 진피 깊은 층 또는 피하층

**표시 범위**:
- 팔자주름 시작점(코 옆) 부분만
- 주름 전체가 아닌 상단 1/3 영역

**좌표**:
```javascript
{
  id: 5,
  category: 'wrinkle',
  color: '#D4A5A5',
  coords: [
    { type: 'ellipse', cx: 39, cy: 50, rx: 2.5, ry: 5, rotate: -12 },  // 왼쪽
    { type: 'ellipse', cx: 61, cy: 50, rx: 2.5, ry: 5, rotate: 12 },   // 오른쪽
  ],
}
```

### ⑥ 옆볼 (Lateral Cheek) - 볼 처짐 개선

**해부학적 기준**:
- **위치**: 협부(Buccal area) 외측, 광대와 턱 사이 중간지점
- **시술 지점**: 처짐 중심부 2-3포인트
- **주사 깊이**: 피하층 또는 근막 위

**표시 범위**:
- 볼 처짐이 가장 두드러지는 중심 영역
- 볼 전체가 아닌 리프팅 포인트

**좌표**:
```javascript
{
  id: 6,
  category: 'volume',
  color: '#A89080',
  coords: [
    { type: 'circle', cx: 24, cy: 48, r: 5.5 },  // 왼쪽 볼
    { type: 'circle', cx: 76, cy: 48, r: 5.5 },  // 오른쪽 볼
  ],
}
```

### ⑦ 턱끝 (Chin) - 턱 볼륨 형성

**해부학적 기준**:
- **위치**: 이부(Mentum), 하순 아래 중앙 돌출부
- **시술 지점**: 턱 정중앙 1-2포인트
- **주사 깊이**: 골막 위 또는 피하층

**표시 범위**:
- 턱 중앙부의 작은 가로 타원 영역
- V라인/턱끝 강조 지점

**좌표**:
```javascript
{
  id: 7,
  category: 'contour',
  color: '#6D5A4D',
  coords: {
    type: 'ellipse',
    cx: 50,     // 턱 정중앙
    cy: 69,     // 턱 높이
    rx: 6,      // 턱 폭
    ry: 3,      // 턱 두께
  },
}
```

### ⑧ 애교살 (Aegyo-sal / Tear Trough)

**해부학적 기준**:
- **위치**: 안와 하연(Infraorbital rim) ~ 눈둘레근 아래
- **시술 지점**: 눈 바로 아래 볼록한 부분 3-4포인트
- **주사 깊이**: 피부 얕은 층 (소량)

**표시 범위**:
- 눈 바로 아래의 좁은 가로 라인
- 눈밑 전체가 아닌 애교살 영역만

**좌표**:
```javascript
{
  id: 8,
  category: 'volume',
  color: '#A89080',
  coords: [
    { type: 'ellipse', cx: 37, cy: 33, rx: 5.5, ry: 2 },  // 왼쪽 눈
    { type: 'ellipse', cx: 63, cy: 33, rx: 5.5, ry: 2 },  // 오른쪽 눈
  ],
}
```

### ⑨ 입술 (Lips) - 입술 볼륨

**해부학적 기준**:

- **시술 지점**: 입술 경계선(버미리온) 및 볼륨부 5-6포인트
- **주사 깊이**: 점막하층

**표시 범위**:
- 입술 중앙부의 작은 가로 타원
- 입술 전체가 아닌 볼륨 포인트

**좌표**:
```javascript

  id: 9,
  category: 'volume',
  color: '#A89080',
  coords: {
    type: 'ellipse',
    cx: 50,     // 입술 정중앙
    cy: 57,     // 입술 높이
    rx: 7,      // 입술 폭
    ry: 2.5,    // 입술 두께
  },
}
```

### ⑩ 눈썹 (Brow) - 눈썹 리프트

**해부학적 기준**:
- **위치**: 미골(Brow bone) 상방, 눈썹 아치 부분
- **시술 지점**: 눈썹꼬리 외측 1/3 아래 1-2포인트
- **주사 깊이**: 골막 위 또는 피하층

**표시 범위**:
- 눈썹 아치 포인트만 (눈썹 방향 따라 살짝 기울임)
- 눈썹 전체가 아닌 리프팅 지점

**좌표**:
```javascript

  id: 10,
  category: 'lift',
  color: '#C9A86C',  // 골드색 (리프팅 카테고리)
  coords: [
    { type: 'ellipse', cx: 34, cy: 24, rx: 5.5, ry: 2, rotate: -10 },  // 왼쪽
    { type: 'ellipse', cx: 66, cy: 24, rx: 5.5, ry: 2, rotate: 10 },   // 오른쪽
```

## 5. 애니메이션 가이드

### 하이라이트 효과 레이어 (안쪽→바깥쪽)

1. **Center Dot** (중심점)
   - 흰색 원, r=1
   - 정확한 주사 포인트 표시
   - 딜레이 후 페이드인

2. **Inner Glow** (내부 광채)
   - fillOpacity: 0.8
   - 메인 영역의 40% 크기
   - 밝은 색조

3. **Main Highlight** (메인 영역)
   - fillOpacity: 0.45
   - strokeWidth: 0.8
   - 실제 시술 범위 표시

4. **Secondary Pulse** (중간 펄스)
   - 메인 영역의 160% 크기
   - 1.5초 주기 애니메이션
   - 부드러운 확산 효과

5. **Outer Pulse** (외부 펄스)
   - 메인 영역의 220% 크기
   - 2초 주기 애니메이션
   - 은은한 확산 효과

### 타이밍 설정
```javascript
// 선택 시 등장 애니메이션
transition: { duration: 0.3, ease: 'easeOut' }

// 펄스 애니메이션
transition: { duration: 2, repeat: Infinity, ease: 'easeInOut' }
```

## 6. 접근성 고려사항

1. **포커스 표시**: 키보드 탐색 시 각 버튼에 명확한 포커스 스타일
2. **색상 대비**: 하이라이트 색상이 이미지 위에서 충분히 구분됨
3. **터치 영역**: 모바일에서 최소 44x44px 터치 영역 확보
4. **스크린 리더**: 각 부위명과 설명이 aria-label로 제공됨

## 7. 좌표 조정 시 주의사항

1. **이미지 비율 유지**: 이미지 변경 시 좌표 재계산 필요
2. **겹침 방지**: 인접한 부위의 하이라이트가 겹치지 않도록
3. **경계 확인**: 하이라이트가 이미지 밖으로 나가지 않도록
4. **양쪽 대칭**: 좌우 대칭 부위는 cx 값이 100을 기준으로 대칭

### 좌표 계산 공식
```javascript
// 왼쪽 좌표를 오른쪽으로 대칭
rightCx = 100 - leftCx

// 예: 왼쪽 관자놀이 cx=21 → 오른쪽 cx=79
```
