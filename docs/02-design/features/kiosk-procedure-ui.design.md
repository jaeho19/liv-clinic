# Design: 키오스크 시술 UI 변경

> Feature: kiosk-procedure-ui
> Plan: `docs/01-plan/features/kiosk-procedure-ui.plan.md`
> Date: 2026-02-19

## 1. 아키텍처 개요

### 데이터 흐름

```
[admin.ts PROCEDURE_CATALOG]  →  KioskView.groupByCategory()  →  시술 선택 UI
                                                                      ↓ (사용자 클릭)
[Supabase procedure_recipes]  →  page.tsx fetch → recipes prop  →  loadRecipeItems()  →  물품 목록 UI
                                                                      ↓ (수량 조절)
[POST /api/admin/inventory/use]  ←  handleSubmit()  ←  usageItems state
```

### 핵심: 코드 변경 불필요

KioskView는 두 데이터 소스만 소비:
1. **`PROCEDURE_CATALOG`** (admin.ts 상수) → 시술 선택 버튼 렌더링
2. **`recipes` prop** (DB fetch) → 물품 목록 렌더링

두 소스가 이미 창 1에서 변경 완료 → **KioskView.tsx 코드 수정 없이 자동 반영**

## 4. 구현 순서

### Step 1: DB 마이그레이션 적용 확인 (5분)
- Supabase에 019 마이그레이션 적용 여부 확인
- 미적용 시 `supabase db push` 또는 SQL 에디터로 직접 실행

### Step 2: 개발 서버 시각 검증 (10분)
- `npm run dev` 실행
- `/admin/inventory` 접속
- 검증 체크리스트 수행:

#### 검증 체크리스트
| # | 테스트 | 기대 결과 |
|---|--------|----------|
| 1 | 리프팅 카테고리 시술 수 | 10개 버튼 (2x5 그리드) |
| 2 | 압토스 클릭 → 옵션 표시 | visage, light lift 500mm, light lift 250mm |
| 3 | 압토스 visage 선택 → 물품 | 해당 물품 1개 표시 |
| 4 | 민트실 클릭 → 옵션 표시 | 리프트업 1개 |
| 5 | 실루엣 소프트 클릭 → 옵션 | 8콘, 12콘 |
| 6 | 네오닥터 클릭 → 옵션 | 23G×60, 27G×50 |
| 7 | 에피티콘 클릭 → 옵션 | Thin, jamber 25G×50 |
| 8 | 콘셀티나 클릭 → 옵션 | 19×100, 19×60, 19×40 |
| 9 | 보톡스 (제오민) 선택 → 물품 | 약물만 표시, 니들 없음 |
| 10 | 써마지 FLX → 600샷 → 물품 | 팁 + 패치 + 플루이드 + 가스 |
| 11 | 써마지 FLX → 아이 → 물품 | 팁 + 패치 + 플루이드 + 가스 |
| 12 | 스컬트라 선택 → 물품 | 스컬트라 + 멸균증류수 |
| 13 | 모바일 뷰 (< 1024px) | 스텝 위저드 정상 동작 |

### Step 3: 이슈 대응 (조건부)
- 검증 중 발견되는 이슈에 대해서만 코드 수정
- 가능한 이슈:
  - 리프팅 10개 그리드가 길어서 UX 불편 → 구분선 또는 라벨 추가 고려
  - DB에 물품 미등록으로 레시피 매칭 실패 → "(미등록)" 표시 확인

## 6. 테스트 전략

- **수동 테스트**: 개발 서버에서 위 체크리스트 13개 항목 직접 확인
- **빌드 테스트**: `npm run build` 통과 확인 (타입 에러 없음)
- **레이아웃 테스트**: PC (1920px) + 모바일 (375px) 양쪽 확인

## 7. 완료 기준

1. 리프팅 카테고리 10개 시술 정상 렌더링
2. 6개 실리프팅 브랜드 옵션 선택 → 물품 로드 정상
3. 보톡스 선택 시 니들 미표시
4. 써마지 옵션 선택 시 패치/플루이드/가스 포함 표시
5. 스컬트라 선택 시 멸균증류수 포함 표시
6. 모바일 스텝 위저드 정상 동작
7. `npm run build` 성공
