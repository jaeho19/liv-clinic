## 좌표 시스템

### 기준
- **X 좌표**: 0% = 왼쪽 끝, 100% = 오른쪽 끝
- **Y 좌표**: 0% = 상단, 100% = 하단
- **rx/ry**: 타원의 수평/수직 반경 (% 단위)

### 이미지 비율 고려사항
- 원본 이미지: 520 x 650 px
- SVG viewBox: 100 x 100 (preserveAspectRatio="none")
- X 좌표는 이미지 너비에, Y 좌표는 이미지 높이에 매핑됨

## 부위별 해부학적 기준 및 좌표

### 1. 이마 (Forehead / Frontalis muscle)

**해부학적 기준:**
- 전두근(Frontalis)은 눈썹 위에서 두피까지 이어지는 근육
- 이마 주름 생성의 주원인
- 보톡스 주입점: 눈썹 위 2-4cm, 이마 중앙에서 측면까지

**좌표:**
```
x: 50%, y: 15%
shape: ellipse (rx: 20%, ry: 8%)
```

**시각적 가이드:**
```
     ┌───────────────────────┐
     │     ████████████      │  ← y: 15% (이마 중앙)
     │    (이마 가로 영역)    │
     │                       │
```

---

### 2. 미간 (Glabella / Procerus & Corrugator)

**해부학적 기준:**
- 추미근(Procerus)과 눈썹주름근(Corrugator supercilii) 위치
- "11자 주름"의 원인 근육
- 보톡스 주입점: 양 눈썹 내측 끝 사이, 코뿌리 바로 위

**좌표:**
```
x: 50%, y: 27%
shape: circle
```

**시각적 가이드:**
```
     │                       │
     │          ●            │  ← y: 27% (눈썹 사이)
     │       (미간점)         │
     │     ●         ●       │  ← 눈 위치
```

---

### 3. 눈가 (Crow's feet / Orbicularis oculi)

**해부학적 기준:**
- 안륜근(Orbicularis oculi) 외측 부분
- 웃을 때 눈가에 생기는 방사상 주름
- 보톡스 주입점: 외안각(눈꼬리)에서 외측 1-2cm

**좌표:**
```
좌측: x: 22%, y: 32%
우측: x: 78%, y: 32%
shape: circle
```

**시각적 가이드:**
```
     │                       │
     │    ●           ●      │  ← y: 32% (눈 옆)
     │   22%         78%     │
     │       (눈가 양쪽)      │
```

---

### 4. 사각턱 (Masseter muscle) ⭐ 핵심 수정 부위

**해부학적 기준:**
- 저작근(Masseter)은 광대활(zygomatic arch)에서 하악각(angle of mandible)까지 이어지는 강력한 저작 근육
- 씹는 동작 시 수축하여 볼록해지는 부분
- 사각턱의 주 원인

**정확한 위치:**
- 상부 부착점: 광대뼈 활(zygomatic arch) 하연
- 하부 부착점: 하악골 외측면, 하악각(mandibular angle)
- 보톡스 주입점: 하악각 상방 약 1-2cm, 이를 꽉 물었을 때 불룩해지는 부위

**좌표:**
```
좌측: x: 20%, y: 58%, rx: 8%, ry: 12%
우측: x: 80%, y: 58%, rx: 8%, ry: 12%
shape: ellipse (세로로 긴 타원 - 저작근 형태 반영)
```

**시각적 가이드:**
```
     │                       │
     │      (코/입 영역)      │
     │                       │
     │  ⬭               ⬭   │  ← y: 58% (턱선 상부)
     │ 20%             80%   │
     │   (하악각 영역)        │
     │                       │
     └───────────────────────┘  ← 턱 끝
```

**주의사항:**
- 마커가 턱 끝(chin)이 아닌 측면 턱선(하악각 주변)에 위치해야 함
- 세로로 긴 타원형으로 저작근의 실제 형태 반영
- 좌우 대칭 유지 필수

---

### 5. 입꼬리 (Mouth corners / Depressor Anguli Oris) ⭐ 핵심 수정 부위

**해부학적 기준:**
- 구각하제근(Depressor Anguli Oris, DAO)은 입꼬리에서 하악골 하연으로 주행
- 입꼬리를 아래로 당기는 근육 (슬픈 표정 유발)
- 입꼬리 처짐, "마리오네트 라인"의 원인

**정확한 위치:**
- 기시점: 하악골 외측면
- 정지점: 입꼬리(구각, oral commissure)
- 보톡스 주입점: 입꼬리 바로 외측, 약간 하방 (약 1cm)

**좌표:**
```
좌측: x: 36%, y: 53%
우측: x: 64%, y: 53%
shape: circle (작은 원형)
```

**시각적 가이드:**
```
     │                       │
     │      ─────────        │  ← 입술 라인
     │     ●         ●       │  ← y: 53% (입꼬리 옆 아래)
     │    36%       64%      │
     │   (DAO 근육 위치)      │
```

**주의사항:**
- 입술 자체가 아닌 입꼬리의 "바로 옆 아래"에 위치
- 입 너비의 끝점에서 약간 외측 하방
- 작은 원형으로 정밀한 주입점 표현

---

### 6. 승모근 (Trapezius muscle) ⭐ 핵심 수정 부위

**해부학적 기준:**
- 승모근은 후두골(occiput), 경추/흉추 극돌기에서 쇄골(clavicle) 외측 1/3과 견봉(acromion)까지 이어지는 대형 삼각형/마름모형 근육
- 상부 섬유(upper trapezius): 어깨를 으쓱하는 동작
- 어깨 라인의 볼륨과 형태를 결정

**정확한 위치:**
- 상부 승모근의 볼륨이 가장 큰 영역: 목-어깨 연결부
- 보톡스 주입점: 경추 옆에서 견봉(어깨뼈 끝) 방향의 상부 섬유
- 쇄골 위가 아닌 어깨 상부 중심

**좌표:**
```
좌측: x: 25%, y: 84%, rx: 12%, ry: 8%
우측: x: 75%, y: 84%, rx: 12%, ry: 8%
shape: ellipse (가로로 넓은 타원 - 승모근 상부 형태 반영)
```

**시각적 가이드:**
```
     │         (목)          │
     │          │            │
     │    ◯─────┼─────◯     │  ← y: 84% (어깨 상부)
     │   25%    │    75%     │
     │  (어깨 라인)           │
     └───────────────────────┘
```

**시각적 영역 설명:**
```
              /\
             /  \       ← 목 뒤
            /    \
           /  ●●  \     ← 주입 영역 (상부 승모근)
          /________\    ← 어깨 라인
```

**주의사항:**
- 쇄골 위(전면)가 아닌 어깨 상부(측면-후면)에 위치
- 목 바로 옆이 아닌 어깨 방향으로 약간 이동
- 가로로 넓은 타원형으로 승모근 상부의 C자/삼각형 형태 반영
