## 추가 참고사항

### 이미지 생성 시 주의점
1. 실제 시술 장면이나 기기는 저작권 문제로 생성하지 않음
2. 의료 관련 비현실적 주장이 암시되는 이미지 지양
3. 자연스러운 피부톤, 과장되지 않은 미용 효과 표현
4. 브랜드 컬러 팔레트 일관성 유지

### 대체 솔루션
- Hero 이미지: 실제 촬영 또는 stock 이미지 사용 권장
- 다이어그램: SVG 직접 코딩으로 정확성 확보
- 아이콘: React 컴포넌트로 SVG 인라인 생성
