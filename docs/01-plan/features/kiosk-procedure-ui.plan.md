# Plan: 키오스크 시술 UI 변경 (창 2)

> 간호팀 수정요청 중 키오스크 시술 UI 관련 항목
> 창 1에서 DB 스키마(018)와 타입(admin.ts), 마이그레이션(019) 이미 커밋됨

## 배경

간호팀의 수정요청 중 키오스크(KioskView) 시술 선택 UI에 영향을 미치는 4가지 항목:
- **#1** 실리프팅 6개 브랜드 분류
- **#4** 보톡스 니들 삭제
- **#6** 써마지 소모품 추가
- **#7** 스컬트라 주사용수 연동

## 현재 상태 분석

### 이미 완료된 작업 (창 1)
1. **admin.ts**: `PROCEDURE_CATALOG`에 6개 실리프팅 브랜드 추가 완료
   - `thread_aptos`, `thread_mint`, `thread_silhouette`, `thread_neodoctor`, `thread_epiticon`, `thread_conseltina`
2. **019_nurse_requests_data.sql**: DB 레시피 변경
   - 보톡스 레시피에서 니들 DELETE
   - 써마지 FLX 600/900/400/아이써마지에 패치/플루이드/가스 INSERT
   - 스컬트라 시술에 멸균증류수 INSERT
   - 기존 실리프팅 PDO/PLLA/PCL/APTOS 레시피 DELETE → 브랜드별 레시피 INSERT

### KioskView.tsx 분석 결과

KioskView는 **완전히 데이터 드리븐** 구조:
- 시술 목록: `PROCEDURE_CATALOG` → `groupByCategory()` → 자동 렌더링
- 물품 목록: `recipes` prop (DB에서 fetch) → `loadRecipeItems()` → 자동 렌더링
- 레시피 유무 체크: `hasRecipeFor()` → DB 기반 자동 판단

**결론: KioskView.tsx 코드 변경이 필요 없을 가능성이 높음**

## 검증 항목

### 1. 실리프팅 6개 브랜드 렌더링 (#1)

**예상 동작**: PROCEDURE_CATALOG에 6개 브랜드가 이미 등록 → 리프팅 카테고리에 자동 표시

**검증 포인트**:
- [ ] 리프팅 그리드에 10개 시술 표시 (울쎄라, 써마지, 덴서티, 슈링크 + 6개 실)
- [ ] 각 브랜드 클릭 시 옵션 표시 (압토스 3개, 민트실 1개, 실루엣 2개, 네오닥터 2개, 에피티콘 2개, 콘셀티나 3개)
- [ ] 옵션 선택 시 해당 물품 로드
- [ ] 2x 그리드에 10개 아이템이 보기 좋게 배치되는지 (모바일/PC)

**잠재적 이슈**:
- 리프팅 카테고리에 10개 시술은 2x5 그리드 = 세로 5줄. 스크롤 필요할 수 있으나 `max-h-[calc(100vh-280px)] overflow-y-auto`로 처리됨

### 2. 보톡스 니들 미표시 (#4)

**예상 동작**: DB에서 니들 레시피 삭제 → `recipes` prop에 니들 없음 → UI에 안 보임

**검증 포인트**:
- [ ] 보톡스 (제오민/하이톡스/제테마더/엘러간) 선택 시 약물만 표시
- [ ] 니들/주사기 항목 미표시

**코드 변경 불필요**: UI는 DB 레시피만 렌더링

### 3. 써마지 소모품 표시 (#6)

**예상 동작**: DB에 패치/플루이드/가스 레시피 추가 → 써마지 옵션 선택 시 자동 표시

**검증 포인트**:
- [ ] 써마지 FLX → 400/600/900샷 선택 시 팁 + 패치 + 플루이드 + 가스 표시
- [ ] 아이써마지 선택 시 동일하게 소모품 표시
- [ ] 각 소모품의 수량 조절(+/-) 작동

**코드 변경 불필요**: UI는 DB 레시피만 렌더링

### 4. 스컬트라 주사용수 표시 (#7)

**예상 동작**: DB에 멸균증류수 레시피 추가 → 스컬트라 선택 시 자동 표시

**검증 포인트**:
- [ ] 스컬트라 선택 시 스컬트라 바이알 + 멸균증류수 함께 표시
- [ ] 멸균증류수 수량이 기본 1로 설정

**코드 변경 불필요**: UI는 DB 레시피만 렌더링

## 리스크

- **DB 마이그레이션 미적용**: 019가 Supabase에 실행되지 않았다면 UI에 반영 안 됨
- **inventory_items 미등록**: 019에서 참조하는 물품(써마지 패치, 플루이드, 가스, 멸균증류수, 실리프팅 브랜드 물품)이 DB에 없으면 INSERT가 무효
- **레시피 이름 불일치**: admin.ts의 `recipeName`과 DB의 `procedure_name`이 정확히 일치해야 함
