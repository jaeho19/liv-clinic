## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem (문제)** | 홈의 Media & News 대표 카드 6개가 **이미지 없는 텍스트 전용 카드**(배지+제목+설명+CTA)라서 시선을 끌지 못하고, 언론보도·소식의 "보여줄 거리"가 글자로만 전달돼 임팩트와 가독성이 약하다. |
| **Solution (해결)** | 카드를 **썸네일 상단형(Image-Top)** 으로 전환한다. 외부 기사 카드는 **기사 OG 썸네일을 로컬로 내려받아** 사용하고, 이미지가 없는 내부 소식은 **브랜드 톤 그라데이션 플레이스홀더**로 폴백한다. 카드 컴포넌트는 홈/`/media`가 공유하므로 한 번의 변경으로 양쪽에 적용된다. |
| **Function·UX 효과** | 6개 카드가 각각 16:9 비주얼을 갖춰 그리드가 "갤러리"처럼 읽힌다. 호버 시 이미지 줌·카드 부상으로 클릭 유도. 빈/깨진 이미지 상태가 0이 되도록 모든 카드에 시각 요소 보장. |
| **Core Value (핵심 가치)** | "텍스트 목록"에서 "비주얼 스토리"로 — 신뢰(언론 노출)와 전문성(학술·글로벌)을 **눈으로 먼저** 전달해 체류·클릭·브랜드 인지를 높인다. |

## 1. 배경 & 문제 정의

### 1.1 현재 상태 (코드 근거)
- **홈 대표 카드**: `featuredMediaNews: FeaturedMediaCard[]` (`src/lib/data/mediaNewsData.ts:269`) — `image` 필드 **없음**. 카드는 `MediaNewsCard.tsx`의 `CardBody`가 배지/연도/출처 + 제목 + 설명 + CTA만 렌더.
- **아카이브 카드**: `/media` 페이지(`media/page.tsx`)도 **동일한 `MediaNewsCard`** 를 사용. `MediaNewsItem`에는 `images?: string[]`가 있으나 **모달 상세에서만** 사용(`MediaNewsModal.tsx:134`), 카드에는 미노출.
- **결론**: 카드 컴포넌트가 홈/아카이브 **단일 공유**라서, 카드에 이미지 슬롯을 추가하면 양쪽에 동시 적용된다. (스코프 대비 변경 지점이 적다)

### 1.2 이미지 자산 실태 (구현 가능성의 핵심)
실제 `public/images/media-news/`에는 **2장만** 존재(`medical-aesthetic-1.jpg`, `medical-aesthetic-2.jpg` — 2026 인터뷰 id 15/f7 전용).

| 홈 카드 | 주제 | 외부 링크 | 보유 이미지 |
|---------|------|:--------:|:-----------:|
| f7 | 메디컬 에스테틱 인터뷰(2026) | ❌ 내부 | ✅ 2장 보유 |
| f1 | SBS 좋은아침 | ✅ vegannews | ❌ → OG |
| f2 | 이슈메이커 커버스토리 | ✅ issuemaker | ❌ → OG |
| f3 | APTOS 트레이너 인증 | ✅ hinews | ❌ → OG |
| f4 | 학회 초청 강연 | ❌ 내부 | ❌ → 폴백 |
| f6 | 셀럽·인플루언서 방문(집계) | ❌ 내부 | ❌ → 폴백(초상권) |

→ **6장 중 5장이 이미지 없음.** 외부 3장은 OG 썸네일로, 내부 2장(f4/f6)은 브랜드 폴백으로 채운다. 이 두 경로를 모두 정의해야 "빈 카드 0개"가 보장된다.

## 4. 이미지 소스 전략 (핵심)

### 4.1 OG 썸네일 추출 파이프라인 (외부 기사 카드)
1회성 데이터 준비 작업으로, 런타임 핫링크가 아니라 **로컬 저장**을 원칙으로 한다.

```
[1] 추출 스크립트 (작업 폴더 C:\dev\LIV_homepage\*.py 컨벤션 준수)
    - mediaNewsData에서 isExternal === true 항목의 link 수집
    - 각 페이지 요청 → <meta property="og:image"> (없으면 twitter:image) 파싱
    - 이미지 다운로드 → public/images/media-news/og/{id}.jpg 저장
    - 성공/실패 리포트 출력 (실패 항목은 폴백 대상으로 표기)
[2] mediaNewsData의 해당 항목 image 필드에 로컬 경로 주입
    예) image: '/images/media-news/og/2.jpg'
[3] 실패/저화질 항목 → 4.3 폴백 또는 브랜드 이미지 수동 교체
```

**로컬 저장을 택하는 이유**: ① 외부 사이트 다운/구조 변경에 빌드가 의존하지 않음 ② `next/image` 최적화(avif/webp) 적용 ③ CLS 방지(규격 고정) ④ 핫링크 차단·트래픽 이슈 회피.

> `next.config.ts`는 이미 `remotePatterns: https/**` 허용 상태라 핫링크도 기술적으로 가능하나, 위 이유로 **로컬 저장을 권장**한다.

### 4.2 OG 품질 검수 기준
- 최소 권장 해상도: 가로 ≥ 600px (16:9 카드에서 깨지지 않을 것)
- 언론사 **공용 로고/플레이스홀더 OG**(기사 무관 일반 이미지)인 경우 → 폴백으로 대체
- 잘림 안전: `object-cover` + 16:9 크롭에서 핵심 피사체가 잘리지 않는지 육안 확인

### 4.3 폴백 플레이스홀더 (내부 소식 / OG 실패)
실제 이미지가 없을 때도 카드가 비지 않도록 **브랜드 톤 비주얼 블록**을 렌더한다.

- 배경: `--color-primary`(#b4988d) ↔ `--color-secondary`(#6d4e42) 그라데이션 (카드 type별 색조 차등)
- 중앙: **LIV 모노그램/로고** + 배지 텍스트(예: `ACADEMIC`, `LIV VISIT`)
- 순수 CSS/SVG로 구현 → 추가 이미지 자산 0, 로딩 비용 0
- f6(셀럽 집계)은 **초상권 이슈로 실사 금지** → 반드시 폴백 또는 브랜드 이미지 사용

### 4.4 카드 이미지 결정 로직 (의사코드)
```
const src = item.image ?? item.images?.[0] ?? null;
// src 있으면 <Image>, 없으면 <BrandPlaceholder type={item.type} badge={item.badge} />
```

## 5. 카드 레이아웃 명세 (Image-Top)

```
┌──────────────────────┐
│   IMAGE / PLACEHOLDER │  ← aspect-[16/9], object-cover, 상단 라운드
│        (16:9)         │     호버 시 scale 1.05 (motion)
├──────────────────────┤
│ [BADGE]  연도 · 출처   │
│ 제목 (line-clamp-2)   │
│ 설명 (line-clamp-3)   │  ← 기존 CardBody 그대로 재사용
│ 자세히 보기 / 기사 보기 →│
└──────────────────────┘
```

- 이미지 컨테이너: `relative aspect-[16/9] overflow-hidden rounded-t-2xl bg-background`
- `next/image fill` + `object-cover` + `sizes`(그리드 컬럼 기준), 1행(홈 3장)은 `priority`, 이후 `loading="lazy"`
- 카드 외곽: 기존 `rounded-2xl border bg-white` 유지하되 상단 패딩 제거(이미지가 모서리까지). 텍스트 영역은 기존 `p-6` 유지
- 호버: 기존 `whileHover y:-6` 유지 + 이미지 `group-hover:scale-105 transition-transform`
- 접근성: `alt={item.title}`(의미 있는 대체텍스트), 폴백은 `role="img" aria-label`

## 6. 데이터 모델 변경

```ts
// mediaNewsData.ts
export interface MediaNewsItem {
  // ...기존 필드
  image?: string;   // 카드 썸네일(로컬 경로). 없으면 images[0] → 폴백 순으로 폴백
}

export interface FeaturedMediaCard {
  // ...기존 필드
  image?: string;   // 카드 썸네일(로컬 경로). 없으면 폴백
}
```

- `image`(카드 썸네일)와 `images`(모달 갤러리)는 **역할 분리**: 카드용/상세용을 혼동하지 않는다.
- 외부 카드: OG 추출 결과 경로 주입. 내부 카드: 보유 이미지(f7) 또는 미지정(→폴백).
