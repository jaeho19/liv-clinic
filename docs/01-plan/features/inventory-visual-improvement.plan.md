# Plan: 재고관리 시각적 개선

## 1. 개요

### 목적
현재 재고관리 페이지(`/admin/inventory`)를 시각적으로 더 직관적이고 관리하기 쉽게 개선한다.
테이블 중심의 단조로운 UI에서 벗어나 **시각적 대시보드 + 카드 기반 레이아웃**으로 전환하여
재고 상태를 한눈에 파악할 수 있도록 한다.

### 현재 상태 분석
- **통계 카드**: 5개의 숫자 카드 (총 품목, 정상, 부족, 소진, 재고가치) - 단순 숫자만 표시
- **경고 배너**: 텍스트 기반 알림
- **재고 현황 탭**: 순수 테이블 형태, 시각적 재고 비율 없음
- **사용 이력 탭**: 단순 테이블 + 기본 바 차트
- **입고 관리 탭**: 리스트 형태
- **상세 패널**: 텍스트 정보 나열

### 개선 후 목표
- 재고 상태를 **색상 + 비율 바 + 아이콘**으로 즉시 파악
- 카테고리별 **비주얼 그루핑**으로 품목 탐색 용이
- **재고 게이지** (프로그레스 바)로 재고 수준 시각화
- 통계 카드에 **미니 트렌드** 정보 추가
- **카드 뷰/테이블 뷰** 전환 지원

## 2. 범위

### In Scope
1. 통계 대시보드 영역 개선 (게이지 차트, 도넛 비율 표시)
2. 재고 현황 탭: 카드 뷰 모드 추가 (재고 게이지 바 포함)
3. 테이블 뷰 개선 (재고 비율 프로그레스 바 인라인 표시)
4. 카테고리별 그루핑 뷰 옵션
5. 사용 이력 탭: 타임라인 스타일 개선
6. 입고 관리 탭: 발주 추천 카드 비주얼 강화

### Out of Scope
- 새로운 API 엔드포인트 추가
- 데이터 모델 변경
- 차트 라이브러리 외부 설치 (CSS/SVG로 구현)
- 모바일 앱 대응 (기존 반응형 유지)

## 3. 기술적 접근

### 의존성
- 외부 라이브러리 추가 없음 (Tailwind CSS + 인라인 SVG로 구현)
- 기존 타입 시스템 그대로 활용

### 구현 전략
1. **재고 현황 탭 리디자인** (가장 핵심)
   - 뷰 전환 버튼 (카드/테이블/그루핑) 추가
   - 카드 뷰: 품목별 카드에 원형 게이지 + 재고 비율
   - 테이블 뷰: 기존 테이블에 인라인 프로그레스 바 추가
   - 그루핑 뷰: 카테고리별 접기/펼치기 그룹

2. **통계 대시보드 강화**
   - 도넛 차트 (SVG): 정상/부족/소진 비율 시각화
   - 카테고리별 재고 분포 미니 바 차트

3. **상세 패널 개선**
   - 원형 게이지로 재고 수준 표시
   - 입출고 타임라인 비주얼 개선

4. **경고 시스템 개선**
   - 긴급도별 색상 그라데이션
   - 소진 임박 품목 카운트다운 표시

## 4. 구현 우선순위

| 순서 | 항목 | 설명 |
|------|------|------|
| 1 | 통계 대시보드 | 도넛 차트 + 카테고리 분포 |
| 2 | 재고 현황 - 테이블 개선 | 인라인 프로그레스 바 + 시각적 상태 |
| 3 | 재고 현황 - 카드 뷰 | 카드형 레이아웃 + 원형 게이지 |
| 4 | 재고 현황 - 그루핑 뷰 | 카테고리별 그룹 + 접기/펼치기 |
| 5 | 경고 배너 개선 | 긴급도 시각화 강화 |
| 6 | 사용 이력 탭 개선 | 타임라인 비주얼 |
| 7 | 입고 관리 탭 개선 | 발주 추천 카드 강화 |
| 8 | 상세 패널 개선 | 게이지 + 타임라인 |

## 5. 위험 요소

- 단일 파일(page.tsx)이 이미 1400줄 이상으로 매우 큼 → 컴포넌트 분리 필요
- SVG 게이지/차트 구현의 정확한 렌더링 확인 필요
- 뷰 모드 전환 시 상태 관리 복잡도 증가
