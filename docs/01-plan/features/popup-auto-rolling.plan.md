# Plan: 팝업 자동 롤링 (Popup Auto Rolling)

> **Feature**: popup-auto-rolling
> **Created**: 2026-02-08
> **Status**: Draft

---

## 1. 현재 상태 분석 (As-Is)

### 현재 팝업 구조
- **PopupManager.tsx**: 여러 팝업을 **순차적으로** 표시 (`currentIndex` 기반)
- **PopupModal.tsx**: 개별 팝업 1개를 모달로 렌더링
- 팝업 닫기 → 다음 팝업이 새로 나타남 (사용자가 팝업을 하나씩 닫아야 함)
- Supabase `popups` 테이블에서 활성 팝업 로드 (`is_active`, `display_start/end` 필터)

### 문제점
1. **UX 불편**: 팝업 하나 닫으면 뒤에 또 팝업이 뜸 → 사용자 짜증 유발
2. **이벤트 노출 저하**: 첫 번째 팝업만 보고 닫으면 나머지 이벤트를 놓침
3. **반복 닫기 부담**: 팝업이 3개면 3번 닫아야 함

---

## 2. 목표 상태 (To-Be)

### 단일 팝업 + 멀티 배너 슬라이더
- **하나의 팝업 모달** 안에 여러 배너를 슬라이드로 통합
- **자동 롤링**: 2.5초 인터벌로 오토 슬라이드
- **인디케이터 UI**: 도트 내비게이션 + 좌우 화살표 버튼
- **사용자 제어**: 수동 슬라이드 전환 가능 (터치 스와이프 포함)
- 기존 "오늘 하루 보지 않기" 기능 유지 (전체 팝업에 대해 적용)

---

## 3. 변경 범위

### 수정 대상 파일

| 파일 | 변경 내용 |
|------|----------|
| `PopupManager.tsx` | 순차 표시 → 전체 팝업 배열을 PopupModal에 전달 |
| `PopupModal.tsx` | 단일 이미지 → 멀티 배너 슬라이더 UI로 변경 |

### 변경하지 않는 것
- DB 스키마 (`popups` 테이블) - 변경 불필요
- Admin 팝업 관리 페이지 - 기존 CRUD 그대로 유지
- API 라우트 - 변경 불필요
- `PopupRow` 타입 - 변경 불필요

## 4. 상세 구현 계획

### 4.1 PopupManager.tsx 변경

**Before**: `currentIndex`로 팝업을 1개씩 순차 표시
**After**: 활성 팝업 배열 전체를 PopupModal에 전달

```
변경 사항:
- currentIndex 상태 제거
- popups 배열 전체를 PopupModal에 props로 전달
- handleClose: 전체 팝업 닫기
- handleDismissToday: 모든 팝업 ID에 대해 dismiss 처리
- 모바일 필터링: show_on_mobile 필터를 배열 레벨에서 적용
```

### 4.2 PopupModal.tsx 변경 (핵심)

**Before**: 단일 popup 이미지 표시
**After**: 멀티 배너 슬라이더

```
새로운 Props:
- popups: PopupRow[]  (단일 popup → 배열)
- onClose: () => void
- onDismissToday: () => void

슬라이더 기능:
1. 자동 롤링 (2.5초 인터벌)
   - setInterval 기반
   - 사용자 인터랙션 시 타이머 리셋 (5초 후 자동 재개)
   - 팝업 1개일 때는 자동 롤링 비활성화

2. 인디케이터 (도트 내비게이션)
   - 하단 배너 영역 위에 도트 배치
   - 현재 슬라이드 활성 도트 강조
   - 도트 클릭으로 슬라이드 이동

3. 화살표 버튼 (선택적)
   - 좌우 화살표로 수동 전환
   - 팝업 2개 이상일 때만 표시

4. 터치 스와이프
   - 모바일 터치 드래그로 슬라이드 전환
   - touchstart/touchend 기반 swipe 감지

5. 슬라이드 전환 애니메이션
   - Framer Motion AnimatePresence 활용
   - 좌→우 / 우→좌 방향 감지 fade+slide 트랜지션
```

### 4.3 UX 디테일

| 항목 | 사양 |
|------|------|
| 자동 롤링 인터벌 | 2.5초 |
| 사용자 조작 후 일시정지 | 5초 후 자동 재개 |
| 전환 애니메이션 | 0.3초 slide + fade |
| 도트 인디케이터 위치 | 이미지 영역 하단 중앙 |
| 도트 크기 | 8px (활성: 10px + 강조색) |
| 화살표 버튼 | 좌우 중앙, 반투명 배경 |
| 터치 스와이프 감도 | 50px 이상 드래그 시 전환 |
| 팝업 1개일 때 | 인디케이터/화살표 숨김, 자동 롤링 없음 (기존과 동일 동작) |

### 4.4 "오늘 하루 보지 않기" 동작 변경

- **Before**: 현재 팝업 1개만 dismiss → 다음 팝업 표시
- **After**: 전체 팝업 모달을 dismiss (모든 활성 팝업 ID를 localStorage에 저장)
- 이유: 단일 모달이므로 "오늘 보지 않기" = 팝업 창 전체를 오늘 안 보겠다는 의미

## 5. 기술 접근

### 사용 기술
- **Framer Motion**: 이미 설치됨 - 슬라이드 전환 애니메이션
- **React hooks**: useState, useEffect, useCallback, useRef
- **터치 이벤트**: 네이티브 touchstart/touchend (라이브러리 불필요)

### 외부 라이브러리
- **추가 설치 없음**: Framer Motion + 커스텀 구현으로 충분
- 프로젝트 기존 패턴과 일관성 유지 (Equipment3DCarousel, Hero 등 모두 커스텀)
