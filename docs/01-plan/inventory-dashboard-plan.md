# PDCA Plan: 재고관리 대시보드 고도화

## 1. 현황 분석

### 1.1 현재 운영 방식 (As-Is)
- **수기 기록**: 엑셀 + 마크다운으로 물품 사용 기록
- **물품 사용 기록**: 날짜 / 고객명(차트번호) / 사용한 물품 / 간호팀 확인
- **정기 재고 카운트**: 1차/2차로 나누어 실물 재고 확인
- **입고 기록**: 별도 관리 (현재 비어있는 템플릿)
- **관리 품목**: 울쎄라(4.5/3.0/1.5), 덴서티(300/600), 포텐자(cp-25/np-25), 써마지(300/600/900/225(I)/450(I)) 등 장비 팁/카트리지 + 주사제 + 소모품

### 1.2 현재 어드민 페이지 (As-Is)
- Mock 데이터 기반 재고 목록 (16개 품목)
- 카테고리: injection / consumable / skincare / equipment
- 입출고 수동 처리 (모달)
- 재고 상태 표시 (정상/부족/소진)
- DB 미연동 (메모리 상태만 관리)

### 1.3 핵심 문제점
1. **사용 기록과 재고가 분리**: 환자 시술 시 물품 사용을 별도로 기록 후 재고에 반영해야 함
2. **이중 작업**: 엑셀에 기록 + 실물 카운트로 교차 확인
3. **실시간 현황 불가**: 현재 남은 수량을 즉시 알 수 없음
4. **이력 추적 어려움**: 누가 언제 얼마나 사용했는지 빠른 조회 불가

## 2. 목표 (To-Be)

### 2.1 핵심 목표
> **환자 시술 시 물품을 선택하면 자동으로 재고가 차감되고, 대시보드에서 실시간 현황을 확인할 수 있는 시스템**

### 2.2 구체적 목표
1. **사용 기록 통합**: 환자별 물품 사용 기록이 곧 재고 차감 트랜잭션
2. **실시간 대시보드**: 현재 재고 현황, 월별 소모량, 카테고리별 상태를 한 눈에 확인
3. **경고 시스템**: 최소 재고 이하 시 시각적 경고
4. **이력 조회**: 기간별/품목별/환자별 사용 내역 조회
5. **입고 관리**: 발주/입고 시 재고 자동 증가

## 3. 카테고리 재분류 (실제 운영 기반)

현재 마크다운/엑셀에서 관리하는 품목 구조를 반영한 카테고리:

| 카테고리 | 설명 | 예시 |
|----------|------|------|
| `device_tip` | 장비 팁/카트리지 | 울쎄라 카트리지, 써마지 팁, 덴서티 팁, 포텐자 팁 |
| `injection` | 주사제 | 보톡스, 필러(쥬비덤/레스틸렌), 리쥬란, 쥬벨룩, 스킨부스터 |
| `thread` | 실리프팅 재료 | PDO 실, 압토스 실 |
| `consumable` | 시술 소모품 | 마취 크림, 니들, 캐뉼라, 알코올솜, 냉각젤 |
| `skincare` | 시술 후 케어 제품 | 재생크림, 선블록, 마스크팩 |

## 4. 데이터 모델

### 4.1 inventory_items (품목 마스터)
```
id              UUID PK
name            TEXT NOT NULL          -- 품목명 (예: "울쎄라 DS 7-3.0")
category        TEXT NOT NULL          -- device_tip, injection, thread, consumable, skincare
sub_category    TEXT                   -- 세부 구분 (예: "ulthera", "thermage")
specification   TEXT                   -- 규격 (예: "3.0mm", "600팁", "100U")
unit            TEXT NOT NULL          -- 단위 (개, 바이알, 시린지, 팁, 박스)
current_stock   INTEGER DEFAULT 0     -- 현재 재고
min_stock       INTEGER DEFAULT 0     -- 최소 재고 (경고 기준)
unit_price      INTEGER DEFAULT 0     -- 단가 (원)
supplier        TEXT                   -- 공급사
storage_note    TEXT                   -- 보관 조건 (냉장보관 등)
is_active       BOOLEAN DEFAULT true
created_at      TIMESTAMPTZ
updated_at      TIMESTAMPTZ
```

### 4.2 inventory_transactions (입출고 트랜잭션)
```
id              UUID PK
item_id         UUID FK → inventory_items
tx_type         TEXT NOT NULL          -- 'use' | 'restock' | 'adjust' | 'dispose'
quantity        INTEGER NOT NULL       -- 양수 (차감/증가 방향은 tx_type으로 결정)
patient_name    TEXT                   -- 환자명 (use 시)
chart_number    TEXT                   -- 차트번호 (use 시)
case_id         UUID FK → cases       -- 운영현황 케이스 연결 (선택적)
note            TEXT                   -- 사유/메모
confirmed_by    TEXT                   -- 확인 간호사
created_by      TEXT                   -- 기록자
created_at      TIMESTAMPTZ
```

### 4.3 procedure_recipes (시술별 기본 소모 레시피)
```
id              UUID PK
procedure_name  TEXT NOT NULL          -- 시술명 (예: "울쎄라 리프팅")
item_id         UUID FK → inventory_items
default_qty     INTEGER NOT NULL       -- 기본 사용량
note            TEXT                   -- 비고
```

### 4.4 inventory_counts (정기 실사 기록)
```
id              UUID PK
item_id         UUID FK → inventory_items
count_type      TEXT NOT NULL          -- '1차', '2차' 등
counted_qty     INTEGER NOT NULL       -- 실사 수량
system_qty      INTEGER NOT NULL       -- 시스템 재고
difference      INTEGER                -- 차이 (실사 - 시스템)
counted_by      TEXT
counted_at      TIMESTAMPTZ
```

## 6. 핵심 워크플로우

### 6.1 환자 시술 시 물품 차감 플로우
```
환자 내원
  ↓
간호사가 "물품 사용" 버튼 클릭
  ↓
환자명/차트번호 입력
  ↓
시술 선택 → 레시피 자동 로드 (수정 가능)
  ↓
확인 간호사 선택 → 저장
  ↓
inventory_transactions 생성 (tx_type: 'use')
  ↓
inventory_items.current_stock 자동 차감
  ↓
min_stock 이하 시 경고 배지 표시
```

### 6.2 입고 플로우
```
물품 도착
  ↓
"입고 등록" 클릭
  ↓
품목 선택 + 수량 입력 + 공급사 확인
  ↓
inventory_transactions 생성 (tx_type: 'restock')
  ↓
inventory_items.current_stock 자동 증가
```

### 6.3 정기 실사 플로우
```
월 1~2회 실물 카운트
  ↓
"재고 실사" 기능에서 실제 수량 입력
  ↓
시스템 수량과 비교 → 차이 표시
  ↓
차이가 있으면 'adjust' 트랜잭션으로 보정
```
