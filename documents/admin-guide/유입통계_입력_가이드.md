## 1. 화면 열기

1. `https://livps.co.kr/admin` 접속 → 이메일/비밀번호로 **로그인**
   (계정이 없으면 실장님에게 요청하세요.)
2. 왼쪽 사이드바 **홈페이지 관리 → 📈 유입 통계** 클릭
3. 상단에 두 개의 탭이 있습니다.

| 탭 | 용도 | 주 사용자 |
|----|------|-----------|
| **일일 입력** | 매일 데이터를 넣고 예약/내원을 체크 | 입력 담당 직원 |
| **통계** | 기간별 집계·차트 보기 | 실장 · 원장 |

> 입력 담당자는 평소 **일일 입력** 탭만 사용하면 됩니다.

![유입 통계 - 일일 입력 화면](inflow_01_entry.png)

## 2. 신규 연락 입력하기

새로운 문의(첫 연락)가 오면 그날 바로, 또는 마감 정산 때 한 줄 추가합니다.

1. 오른쪽 위 **`+ 신규 리드`** 버튼 클릭
2. 뜨는 창에서 아래 칸을 채웁니다.

| 칸 | 설명 | 필수? |
|----|------|:----:|
| **연락일** | 처음 문의가 들어온 날 (기본값: 오늘) | ✅ |
| **채널** | 어떤 경로로 문의가 왔는지 ([3번](#3-채널-종류) 참고) | ✅ |
| **에이전시** | 에이전시 소개 환자면 에이전시명 입력, 아니면 **비움** ([4번](#4-에이전시--신규재진-입력-규칙)) | |
| **구분** | **신규** / **재진**(재방문) 중 선택 | ✅ |
| **이름** | 알면 입력 | |
| **전화** | 알면 입력 | |
| **위챗 ID** | 위챗 문의면 입력 | |
| **카카오 ID** | 카카오 문의면 입력 | |
| **관심/예약 시술** | 문의한 시술 (예: 써마지, 보톡스) | |
| **비고** | 기타 메모 | |

3. **저장** 클릭 → 목록에 한 줄이 추가됩니다.

> 💡 이름을 몰라도 됩니다. **위챗 ID·카카오 ID·전화** 중 하나만 적어두면 나중에 검색으로 찾을 수 있습니다.

![신규 리드 입력 창](inflow_02_modal.png)

## 3. 채널 종류

"채널"은 **고객이 우리에게 처음 닿은 경로**입니다. 화면의 채널 목록과 뜻은 다음과 같습니다.

| 채널 | 언제 선택 |
|------|-----------|
| **위챗** | 위챗(WeChat)으로 들어온 문의 |
| **카카오톡** | 카카오톡 채널 문의 |
| **네이버** | 네이버 예약·톡톡·블로그 등 |
| **전화** | 전화 상담 |
| **워크인** | 예약 없이 직접 방문 |
| **홈페이지** | 홈페이지 상담 신청 폼 |
| **라이브챗** | 홈페이지 우측 하단 실시간 채팅 |
| **기타** | 위에 없는 경로 (비고에 설명) |

> 채널을 잘 모를 때는 가장 가까운 것을 고르고 **비고**에 메모하세요. (예: "지인 소개")

## 4. 에이전시 / 신규·재진 입력 규칙

### 에이전시 칸 — **최초 유입 기준으로 고정**
- **첫 방문이 에이전시(예: 바이올렛) 소개**였던 환자 → 에이전시명 입력. 이후 **재진도 같은 에이전시명**으로 유지합니다.
- **첫 유입이 우리 채널(위챗·홈페이지·전화 등) 직접 유입**이었으면 → 에이전시 칸은 **비웁니다**. 재진도 계속 비움.

> ✅ 한 문장 규칙: **"처음에 누구를 통해 왔는가"로 정하고, 그 뒤에는 바꾸지 않는다.**
> 에이전시 칸 입력은 위챗 글자로 적지 말고 칸 안의 추천 목록(예: 바이올렛)을 쓰면 통일됩니다.

### 구분 칸 — 신규 / 재진
- **신규**: 우리 병원에 처음 문의/방문하는 분
- **재진**(재방문): 이전에 시술·방문 이력이 있는 분

> ❓ 애매하면 실장님께 확인 후 입력하세요. (에이전시 인정 기준은 변경될 수 있어, 우선 위 규칙대로 일관되게 입력합니다.)

## 5. 예약·내원 표시하기

문의했던 고객이 **예약하거나 내원하면**, 새 줄을 만들지 말고 **기존 줄을 찾아 체크**합니다.

### ① 기존 리드 찾기
- 상단 **검색창**에 이름·위챗ID·카카오ID·전화 중 하나를 입력하면 **전 기간**에서 찾아줍니다.
- (오늘 들어온 건이면 검색 없이 목록에 바로 보입니다.)

### ② 예약/내원 체크
- 해당 줄의 **`예약`** 버튼을 누르면 → 예약 처리되고 **예약일이 오늘 날짜로 자동 입력**됩니다.
- **`내원`** 버튼을 누르면 → 내원 처리되고 **내원일이 자동 입력**됩니다.
- 날짜가 실제와 다르면 줄의 **`수정`**을 눌러 예약일/내원일을 직접 바꿀 수 있습니다.

> ⚠️ **중복 입력 금지**: 예약/내원을 적기 전 **반드시 검색으로 기존 줄을 먼저 찾으세요.** 같은 사람을 또 추가하면 통계가 부풀려집니다.

![예약·내원 토글](inflow_03_toggle.png)

## 6. 하루 마감 점검

입력을 마치면 화면 상단의 **요약 카드 3개**로 그날 숫자를 확인합니다.

| 카드 | 뜻 |
|------|----|
| **신규 연락** | 그 날짜에 처음 문의한 건수 |
| **예약** | 그 날짜에 예약 전환된 건수 |
| **내원** | 그 날짜에 실제 내원한 건수 |

- 날짜는 상단의 **‹ / 달력 / › / 오늘** 버튼으로 이동합니다.
- 숫자가 실제와 맞는지 확인하고 마감합니다.
- (선택) **CSV** 버튼을 누르면 그 날짜(또는 검색 결과)를 엑셀 파일로 내려받을 수 있습니다.

## 7. 입력 규칙 요약

| ✅ 이렇게 하세요 (Do) | ❌ 이러지 마세요 (Don't) |
|----------------------|-------------------------|
| 새 문의 = 새 줄 1개 추가 | 같은 사람을 예약·내원 때 또 추가 |
| 예약/내원은 **기존 줄에 체크** | 검색 없이 무작정 새 줄 만들기 |
| 위챗ID·카카오ID·전화 중 하나는 꼭 입력 | 식별 정보 전부 비워두기 |
| 에이전시는 **최초 유입 기준**으로 고정 | 재진 때 에이전시명을 임의로 바꾸기 |
| 매일 마감 시 빠짐없이 입력 | 며칠 몰아서 기억으로 입력 |
| 애매하면 비고에 메모 | 모르는 채 임의 추측으로 채우기 |

## 8. 통계 탭 보기 (참고)

주로 실장·원장이 보는 화면이지만, 누구나 열어볼 수 있습니다.

- **기간 필터**: 최근 7일 / 30일 / 90일 / 이번 달
- **KPI 카드**: 신규 연락 · 예약 · 내원 · 전환율(예약% / 내원%)
- **전환 퍼널**: 신규 연락 → 예약 → 내원 단계별 비율
- **채널별 신규 연락**: 어떤 경로가 많은지
- **에이전시 vs 직접 유입**: 신규 연락 기준, 괄호 안은 내원 수
- **일자별 추세**: 날짜별 연락/예약/내원 막대그래프

> 통계는 **일일 입력 데이터가 정확할수록** 정확해집니다. 매일 성실한 입력이 가장 중요합니다.

## 9. 자주 묻는 질문

**Q. 예전에 문의했던 사람이 오늘 또 문의했어요.**
→ 새 줄을 만들지 말고, 검색으로 찾아 **그 줄**에서 처리하세요. (이미 내원까지 끝난 별개 건이라면 실장님 안내에 따릅니다.)

**Q. 채널을 잘 모르겠어요.**
→ 가장 가까운 채널을 고르고 **비고**에 상황을 적어주세요.

**Q. 이름을 몰라요.**
→ 비워도 됩니다. 대신 **위챗ID/카카오ID/전화** 중 하나는 꼭 적어주세요(나중에 검색용).

**Q. 예약했다가 취소됐어요.**
→ 그 줄에서 **예약** 버튼을 다시 눌러 끄면 됩니다(예약일도 지워집니다). 상황은 비고에 메모.

**Q. 날짜를 잘못 넣었어요.**
→ 줄의 **수정**을 눌러 연락일/예약일/내원일을 고칠 수 있습니다.

**Q. 위챗과 카카오로 둘 다 문의한 사람은요?**
→ 한 줄에 위챗ID·카카오ID를 **둘 다** 적고, 채널은 **처음 닿은** 쪽으로 선택하세요.

**Q. 에이전시 환자인지 확실하지 않아요.**
→ 우선 비우고 **비고에 "에이전시 소개 추정"**이라고 적은 뒤 실장님께 확인하세요.

## 10. 부록: 입력 예시

**예시 1 — 위챗 신규 → 예약 → 내원**
1. 6/19 위챗으로 써마지 문의 → `+ 신규 리드`: 연락일 6/19, 채널 **위챗**, 구분 **신규**, 위챗ID `liv_kim`, 시술 "써마지" → 저장
2. 6/20 예약 확정 → 검색 `liv_kim` → 그 줄 **예약** 클릭(예약일 자동)
3. 6/22 내원 → 검색 → **내원** 클릭(내원일 자동)

**예시 2 — 에이전시(바이올렛) 소개 건**
- 연락일 입력, 채널 **위챗**, **에이전시** 칸에 `바이올렛`, 구분 **신규** → 저장
- 이후 같은 환자가 재진해도 에이전시는 **계속 `바이올렛`** 유지(최초 유입 기준).

**예시 3 — 재진(직접 유입 고객)**
- 과거 직접 유입(에이전시 없음)이었던 단골이 다시 전화 문의 → 채널 **전화**, **에이전시 비움**, 구분 **재진** → 저장
