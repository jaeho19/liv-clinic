| 해상도 | 1080×1920 | **1080×1920** |
| 프레임레이트 | 30fps CFR | **30/1, fps_mode cfr** |

**비트레이트가 계획서의 "약 10Mbps"보다 낮은 이유**: 목표 비트레이트(-b:v 10M) 대신 품질 기준
인코딩(CRF 14)을 썼다. 내용이 정지 그래픽과 블러 배경 위주여서 같은 화질을 훨씬 적은 비트로 담는다.
동일 프레임을 렌더 원본 PNG와 비교한 결과 **PSNR 43.9dB**, 대비를 7배 강조해 확인해도
밴딩·블로킹이 보이지 않았다(`edit/stills/qc_band_compare.png`). 비트를 5배 더 써도 보이는 차이가
없어 품질 기준을 택했다. 더 높은 비트레이트 마스터가 필요하면 `edit/scenes/M01~M12.mp4`(CRF 12)에서
재인코딩하면 된다.

## 2. 전 구간 고정 요소 — 통과

2fps로 **720프레임을 전수 검사**했다. 모든 프레임에서:

- 상단 좌측 LIV 로고 영역에 밝은 픽셀 존재 — 누락 **0건**
- 상단 우측 "리브성형외과" 영역에 밝은 픽셀 존재 — 누락 **0건**
- 하단 "이 건물 4층" 로즈 필(#b4988d) 색 일치 — 누락 **0건**
- 하단 우측 전화번호 02-797-2773 상시 노출

어느 구간에서 보기 시작해도 병원명·층수·연락처가 화면에 있다.

## 3. 검은 프레임 / 정지 — 통과

- `blackdetect` (pic_th 0.98): **검출 0건**. 720프레임 평균 휘도 최솟값 34.5로 완전 암전 구간 없음.
- `freezedetect` (n=0.001, d=3초): **검출 0건**.
  2.5초 기준으로는 5구간(최장 3.13초)이 잡히는데, 카드 조판이 고정된 홀드 구간이며 배경은 계속
  천천히 움직인다. 첫 렌더에서 3~5.7초짜리 완전 정지 구간이 나와 배경 이동량을 키워 해결했다.
- 장면 전환 12곳은 0.4초 크로스 디졸브다. 고정 크롬은 디졸브 위에 그려 전환 중에도 떨림이 없다
  (`edit/stills/transition_sheet.png`).

## 5. 내용 검수 (스틸 육안 확인)

12개 장면 × 5시점 + 전환부를 최종 파일에서 추출해 확인했다(`edit/stills/final_sheet_a.png`,
`final_sheet_b.png`, `transition_sheet.png`).

- 네 장비명이 **M01 · M06 · M10 · M12**에 반복 노출된다. M02~M05는 각각 한 장비를 8초 이상 유지한다.
- 장비명과 사진 대조: 울쎄라→`equipment_ultherapy.png`, 써마지 FLX→`equipment_thermage.png`,
  덴서티→`equipment_density.png`. **악센트 프라임에는 어떤 장비 사진도 붙이지 않았다**
  (울쎄라피 프라임과 혼동 없음).
- 덴서티는 계획서대로 **"고주파 기반 장비"**로 표기했다. HIFU+RF 표현은 쓰지 않았다.
- 원장 소개는 D01 실사진만 사용했다. 표정·손동작·발언·진료 장면을 생성하지 않았고, 프레임 이동과
  크기 조절만 적용했다. 학력·논문·수상 문구는 넣지 않았다.
- 전후 비교, 효과 보장, 수치, 타 병원 비교 문구가 없다.
- 오탈자·잘린 글자 없음. 모든 조판은 좌우 72px 안전여백 안에 있고, 긴 문장은 폭을 넘으면
  자동으로 크기를 줄이도록 되어 있다(`fit_size`).

## 8. 현장에서 확인해야 할 항목 (이 세션에서 검증하지 않음)

- 1층 공용 모니터의 실제 재생: 반복 재생 설정, 화면 비율 처리(레터박스 여부), 밝기
- **2~3m 거리에서의 가독성** — 화면 크기와 설치 높이에 따라 달라진다. 자막 크기는 1080×1920 기준
  제목 88~116px, 장비명 58~112px로 잡았으나 현장 확인 후 조정이 필요할 수 있다
- 실제 스마트폰 카메라로 화면의 QR 스캔 (파일 프레임에서는 6개 시점 모두 디코딩 확인)
- 플레이어가 오디오 트랙을 요구하는지 → 요구하면 `..._silentAAC.mp4`를 쓰면 된다
- 의료광고 관련 최종 문구·절차 검토. **이 검수는 심의 완료를 뜻하지 않는다**
- `liv-clinic.net/ko/contact` 페이지는 열리는 것만 확인했고 실제 예약 접수는 실행하지 않았다

## 9. 재현 방법

```bash
cd D:\dev\LIV_homepage\output\lifting-city
python edit/prep_assets.py                       # 에셋 전처리
python edit/render_video.py --scene 1            # 장면 1개만 재렌더
python edit/render_video.py --stills 0,15,354    # 특정 시점 스틸
# 12개 장면 병렬 렌더 후
ffmpeg -f concat -safe 0 -i edit/scenes/concat.txt -c:v libx264 -preset slow -crf 14 \
  -maxrate 16M -bufsize 28M -pix_fmt yuv420p -r 30 -fps_mode cfr -g 60 -an \
  -movflags +faststart renders/LIV_lifting_city_01_1080x1920_6min_silent.mp4
python edit/qc_check.py                          # 자동 검수 재실행
```

장면 12개 병렬 렌더 약 66초, 마스터 인코딩 약 3분(24코어 기준).
