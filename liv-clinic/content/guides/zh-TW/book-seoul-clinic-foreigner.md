想趁著去首爾旅行順便做音波拉提、鳳凰電波或肉毒桿菌素，卻不知道怎麼和診所聯絡，也擔心不找代辦會不會比較貴、語言不通怎麼辦？其實流程很簡單：用 LINE 或 WhatsApp 加診所好友，把照片和行程傳過去，收到報價後確定日期，預約就完成了。外國患者與韓國患者適用同一份價目表，預約面診不需要付訂金，中文諮詢和翻譯也不另外收費。

本文以 LIV整形外科 為例說明整個過程。LIV 位於首爾江南新沙站（地鐵3號線）4號出口步行1分鐘處，緊鄰林蔭道，專注於非手術抗老療程：拉提緊緻、肉毒桿菌素、玻尿酸和水光針等。這類療程大多在30~90分鐘內完成、不需住院，很多人到院當天就做完了。

## 三步預約：加好友 → 拿報價 → 定日期

- **第一步，加好友。** LINE ID icps7972773，或 WhatsApp +82 10-6888-2773，直接用中文傳訊息就可以。用 WeChat（livps0414）或網站線上客服也行。
- **第二步，遠距諮詢拿報價。** 傳幾張照片、說明你的困擾，診所會給出適合的方案和明確的報價；諮詢會在一個工作天內得到回覆。
- **第三步，確定日期。** 依你的航班和行程選時間。預約面診不需要付訂金，價格就是[價目表](/pricing)上公開的價格，外國人沒有額外加價。

## 不找代辦，自己先確認這三件事

自己直接預約，也代表要自己把關。到任何一家診所之前都值得確認三件事，這裡順便說明 LIV 的情況。

1. **儀器是不是正品？** LIV整形外科 是音波拉提（Ultherapy Prime）正品認證診所及鳳凰電波（Thermage FLX）合作診所，只使用正品認證的手具（探頭）治療，你可以在治療前親自確認。
2. **由誰規劃、由誰操作？** 所有療程都由整形外科專科醫生金秀英代表院長規劃並主持，院長發表過 SCI 收錄論文4篇。經歷見[醫療團隊](/about/staff)。
3. **價格是否公開？** 是的。[價目表](/pricing)對所有人公開（以單次計算、未含增值稅），外國人與韓國人用同一份，最終金額在面診後確定。

## 從傳訊息到回國後的 5 個步驟

1. **聯絡診所** — 透過 LINE 或 WhatsApp（或 WeChat、網站線上客服）用中文傳訊息，一個工作天內會收到回覆。
2. **遠距諮詢與報價** — 分享困擾和照片，診所推薦適合的療程並傳送明確的報價。報價與[價目表](/pricing)一致：以單次計算、未含增值稅，最終金額在到院面診後確定。
3. **預約到院日期** — 選擇符合行程的日期和時間並預約。預約面診不需要訂金，因此如果行程有變（包括航班延誤），透過同一個管道盡早告知診所即可。
4. **到院面診、當天治療** — 由醫師面診做最後確認，多數情況下當天即可進行治療。
5. **遠距術後追蹤** — 回國後，透過 LINE、WhatsApp 或線上客服追蹤恢復情況、解答疑問。

## 到院當天的流程

- **抵達**：地鐵3號線新沙站4號出口步行1分鐘，自恩大廈4樓。診所緊鄰林蔭道，療程結束後可以步行前往。
- **面診**：由整形外科專科醫師面診，確認遠距諮詢時定下的方案。可以用中文溝通，如需翻譯可免費安排，預約時說明即可。
- **準備**：視療程而定，可能先敷麻醉藥膏。[音波拉提 Prime](/lifting/ulthera)敷約30分鐘；[鳳凰電波 FLX](/lifting/thermage)不需麻醉（以震動技術減輕疼痛）；[肉毒桿菌素](/antiaging/botox)不需麻醉，有需要也可以敷麻醉藥膏。
- **治療**：大多數非手術療程總共30~90分鐘（音波拉提 Prime 60~90分鐘、鳳凰電波 FLX 45~60分鐘、肉毒桿菌素10~20分鐘），不需住院。
- **離開前**：領取中文的書面術後護理指南。

> 音波拉提 Prime、鳳凰電波 FLX、肉毒桿菌素、玻尿酸、水光針都是當天一次完成，不需複診。埋線拉提建議約一週後複查，但並非必要，也可以透過照片遠距複查。以上時間為一般參考，實際以面診時確認為準。

## 付款、翻譯與術後追蹤

- **付款**：可使用 Visa、Mastercard、American Express、JCB、銀聯（UnionPay）等境外發行的信用卡，也可以用韓元（KRW）現金付款。沒有訂金，也沒有「外國人價格」，到院後依公開的價格付款。只做面診時，1對1專業諮詢費用為1萬韓元，當天進行治療時可從治療費用中全額抵扣。付款以境外發行的信用卡和韓元現金為主，LINE Pay、支付寶、微信支付等行動支付是否可用，請在到院前透過 LINE 或線上客服先確認。
- **翻譯**：支援中文、英語、日語諮詢，如需翻譯可免費安排，語言服務不收取額外費用。到院前的 LINE 或 WhatsApp 溝通也直接用中文。
- **回國後的追蹤**：透過同一個 LINE、WhatsApp 或線上客服傳照片，診所會查看恢復情況並指導護理。離院時還會拿到中文的書面術後護理指南。更多外國患者常問的問題見[醫療資訊頁面](/medical)。

## 傳訊息之前

以上是通用流程。實際做什麼療程、做多少、多少費用，都在面診時確定。先把行程日期和幾張照片傳到 LINE 或 WhatsApp，剩下的交給診所。各管道的入口在[國際患者頁面](/international)。

## FAQ

### 預約需要付訂金嗎？

不需要。預約面診不需要支付訂金，費用到院後支付，適用與韓國患者相同的價目表。

### 多久能收到回覆？

一個工作天內。LINE、WhatsApp、WeChat、網站線上客服和諮詢表單都一樣。診所營業時間為週一至週五 10:00–19:00、週六 10:00–16:00（韓國時間）。

### 中文諮詢或翻譯要收費嗎？

不收費。支援中文、英語、日語諮詢，翻譯依需求免費安排，語言服務沒有額外費用。

### 可以用台灣或香港發行的信用卡付款嗎？

可以。Visa、Mastercard、American Express、JCB、銀聯（UnionPay）等境外發行的信用卡都可以使用，也接受韓元（KRW）現金。

### 面診當天可以直接做嗎？

多數情況下可以。大多數非手術療程30~90分鐘完成、不需住院，很多人到院當天就做完了。最終以醫師面診後的判斷為準。

### 回國後有問題怎麼辦？

用 LINE 或 WhatsApp 傳照片和問題給診所，醫療團隊會遠距查看恢復情況並給出建議，手邊還有中文的術後護理指南可以對照。
