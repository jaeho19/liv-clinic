料金表を見れば「いくらから」は分かります。でも、実際に会計でいくらになるのか——税は含まれているのか、カウンセリングは有料か、予約金は必要か、外国人は割高にならないか——は料金表だけでは分かりにくいものです。この記事では、LIV美容クリニックが公開している情報だけを使って、その疑問に答えます。LIV美容クリニックは新沙(シンサ)駅4番出口から徒歩1分にある非手術アンチエイジング専門のクリニックです。先に結論を言うと、料金表は全員共通、1回あたり・韓国ウォン建て・VAT別途の表示で、正確な金額はカウンセリングで確定します。

## まず結論

- **料金表は1つだけ。** 外国人患者も韓国人患者と同じ料金表が適用されます。外国人向けの上乗せはありません。
- **1回あたり・ウォン建て・VAT（付加価値税）別途。** 表示料金にVATが加算されます。
- **「〜」は「から」。** 正確な料金はカウンセリング後に決まります。
- **カウンセリング料は1万ウォン。** 当日施術を受ける場合は、施術料金から全額差し引かれます。
- **通訳は無料。** 多言語対応のための追加費用もありません。
- **予約金は不要。** カウンセリングの予約に予約金はかかりません。
- **お支払い：** Visa・Mastercard・American Express・JCB・UnionPay、または韓国ウォン現金。カード分割払いも可能です。

## 公開料金表の読み方

[料金案内ページ](/pricing)には糸リフト・フィラー・サーマジ・ウルセラの4区分が公開されており、そのほかの施術は各施術ページ（[ボトックス](/antiaging/botox)、[スキンブースター](/antiaging/skinbooster)、[レーザー](/laser)など）に料金表があります。どの行も「項目・基準・料金」の3つでできています。

| 表示 | 意味 |
|---|---|
| 1,560,000ウォン〜 | 韓国ウォン建ての開始料金。「〜」は「から」。 |
| 「400-800ショット」「1cc」「8本」「100IUあたり」「1回」などの基準 | その料金が何に対するものか。実際に必要な量はカウンセリングで決まります。 |
| 「1回基準」 | コースではなく、施術1回分の料金。 |
| 「すべての料金はVAT別途」 | お支払い時に表示料金へVATが加算されます。 |
| 「カウンセリング時に詳細をご案内」 | 公開料金がない項目。対面またはメッセージで見積もりを受け取ります。 |

料金表から、いくつか例を挙げます。

| 施術 | 基準 | 公開料金（1回・VAT別途） |
|---|---|---|
| ウルセラ 全顔 | 400-800ショット | 1,560,000ウォン〜 |
| サーマジFLX | 600ショット | 2,400,000ウォン〜 |
| 糸リフト ミント | 8本 | 800,000ウォン〜 |
| フィラー 国産 | 1cc | 200,000ウォン〜 |
| 輪郭ボトックス（エラ・こめかみ）国産 | — | 60,000ウォン〜 |
| 肌トーン改善のレーザートーニング | 1回 | 150,000ウォン〜 |

料金表の下には、クリニックの注記があります。「上記の料金は1回基準で、正確な料金はカウンセリング後に決定されます。個人の肌状態、施術範囲、使用製品によって最終費用は変わる場合があります」。

## 料金に加わるもの・加わらないもの

| 項目 | 金額 | 補足 |
|---|---|---|
| 施術料金 | 公開料金をもとにカウンセリングで確定 | 1回あたり・ウォン建て |
| VAT（付加価値税） | 施術料金に加算 | 料金表は税別表示 |
| 1:1カウンセリング | 1万ウォン | 当日施術を受ける場合は施術料金から全額差し引き |
| 通訳（日本語・英語・中国語） | 無料 | 希望すれば手配 |
| 外国人向けの追加料金 | なし | 韓国人患者と同じ料金表 |
| カウンセリング予約の予約金 | なし | お支払いは来院時 |

料金表は税別なので、見積もりを受け取るときは「VAT込みの総額」を確認しておくと安心です。他院と比べるときも、この総額でそろえるのが一番分かりやすい方法です。

## 計算例（あくまで説明用です）

以下はクリニックの公開料金だけを使った例で、仕組みを説明するためのものです。見積もりではありません。公開料金はすべて開始料金で、実際の金額はカウンセリング後に確定します。

**例1：カウンセリングだけ受ける場合。** 院長の説明を聞いて、いったん持ち帰って検討する。

| 内訳 | 金額 |
|---|---|
| 1:1カウンセリング | 1万ウォン |
| お支払い | 1万ウォン |

**例2：当日に小さな施術を1つ。** カウンセリング後、そのまま国産製品で輪郭ボトックスを受ける。

| 内訳 | 金額 |
|---|---|
| 輪郭ボトックス（エラ・こめかみ）国産 | 60,000ウォン〜 |
| 1:1カウンセリング | 1万ウォン（施術料金から全額差し引き） |
| VAT | 別途加算 |
| お支払い | 60,000ウォン〜 ＋ VAT |

**例3：1回の来院で2つの施術。** ウルセラ全顔と、肌トーン改善のレーザートーニング1回。

| 内訳 | 金額 |
|---|---|
| ウルセラ 全顔（400-800ショット） | 1,560,000ウォン〜 |
| 肌トーン改善のレーザートーニング 1回 | 150,000ウォン〜 |
| 公開開始料金の合計 | 1,710,000ウォン〜 |
| 1:1カウンセリング | 1万ウォン（施術料金から全額差し引き） |
| VAT | 別途加算 |
| お支払い | 1,710,000ウォン〜 ＋ VAT |

どの例でも、当日施術を受ければカウンセリング料は施術料金に上乗せされず、全額差し引かれます。実際の金額を左右するのは、料金表では事前に分からない部分——ショット数・cc数・本数がどれだけ必要か、どの製品を選ぶか——です。

## お支払い方法と分割払い

- **海外発行カード：** Visa、Mastercard、American Express、JCB、UnionPay（銀聯）が使えます。
- **現金：** 韓国ウォン（KRW）。
- **分割払い：** カード分割払いが可能です。無利息分割の条件はカード会社と決済金額によって異なるため、カウンセリング時にお問い合わせください。[검수 필요: 해외 발급 카드도 할부 결제가 되는지]
- **通貨：** 料金は韓国ウォン建てです。カードで支払う場合、明細に載る金額は適用される為替レートによって変わります。
- **支払うタイミング：** 来院時にお支払いいただきます。カウンセリングの予約に予約金はかかりません。予定が変わったときは、同じLINEやチャットでなるべく早めにお知らせください。

お支払いについて個別のご質問があれば、カウンセリング時にお伝えください。最初のメッセージに書き添えていただいても構いません。

## カウンセリングで決まること

LINEなどで届く見積もりは、写真をもとにした目安です。計画と料金が確定するのは、形成外科専門医との対面カウンセリングです。

- **どの施術にするか。** 1つの施術でよいか、組み合わせるか。
- **どれだけ必要か。** [ウルセラ](/lifting/ulthera)や[サーマジ](/lifting/thermage)のショット数、[フィラー](/antiaging/filler)のcc数、[ボトックス](/antiaging/botox)の単位と製品、糸の本数、レーザーの回数。
- **どの製品にするか。** 国産・国産プレミアム・輸入のように段階がある項目。
- **最終料金。** VATを含めた総額。

カウンセリングだけ受けて、後日決めることもできます。クリニックも「十分にご検討いただいてからお決めいただいて大丈夫です」と案内しています。

## 渡韓前に見積もりを取る流れ

1. **問い合わせ：** LINE（ID: icps7972773）、当サイトのライブチャット、[お問い合わせフォーム](/contact)に日本語でメッセージを送ります。営業日1日以内に返信があります。
2. **お悩みと写真2〜3枚、** ソウル滞在の日程を伝えます。
3. **見積もりを受け取る：** 適した施術の提案と料金の見積もりが届きます。VAT込みの総額も聞いておきましょう。
4. **日時を予約：** 旅行日程に合う日時を選びます。予約金は不要です。
5. **来院して確定：** 院長が対面で計画と料金を確定し、多くの場合その日のうちに施術を受けます。

診療時間は平日10:00〜19:00、土曜10:00〜16:00、日曜休診（韓国時間）です。

## FAQ

### 外国人は韓国人より料金が高くなりますか？

いいえ。外国人患者も韓国人患者と同じ料金表が適用され、料金は公開されているので来院前に確認できます。多言語対応や通訳のための追加費用もかかりません。

### 表示料金は税込みですか？

いいえ。公開料金はすべてVAT（付加価値税）別途で、お支払い時に加算されます。見積もりを受け取るときに、VAT込みの総額をご確認ください。

### カウンセリング料はかかりますか？戻ってきますか？

1:1カウンセリングは1万ウォンです。当日施術を受ける場合は、施術料金から全額差し引かれます。カウンセリングだけ受けて、後日決めることもできます。

### 予約金は必要ですか？

必要ありません。カウンセリングのご予約に予約金はかからず、お支払いは来院時です。

### 日本のクレジットカードや分割払いは使えますか？

海外発行のVisa、Mastercard、American Express、JCB、UnionPayが使え、韓国ウォン現金でもお支払いいただけます。カード分割払いも可能ですが、無利息分割の条件はカード会社と金額によって異なるため、カウンセリング時にご確認ください。
