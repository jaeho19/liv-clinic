- 즉, "신규 페이지가 타언어에 미반영"이라는 우려와 달리 **메시지 카탈로그는 전 언어 완역**.

### 1.2 ICU `chat.unreadAria` 차이 — ✅ 비결함
- ko: `{count, plural, other {새 메시지 #개}}`
- en: `{count, plural, one {1 new message} other {# new messages}}`
- 한국어는 복수 단/복수 구분이 없어 `other`만, 영어는 `one/other`를 둠 → **언어별 올바른 복수 처리.** 버그 아님. (스캐너의 ICU "mismatch" 플래그는 false positive.)

### 1.3 파일 포맷
- 메시지 JSON: **CRLF 개행**, 2-space indent, trailing newline. (수정 시 반드시 보존)
