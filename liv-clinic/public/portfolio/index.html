FAQ
자주 묻는 질문
궁금하신 점이 있으시면 언제든 문의해 주세요
제작 기간은 얼마나 걸리나요?

기본 웹사이트는 4주 내에 완성됩니다. 다국어 4개국어 포함, 관리자 시스템 포함 기준입니다. 페이지 수가 많거나 특수 기능이 필요한 경우 1~2주 추가될 수 있습니다.

다국어는 어떤 언어를 지원하나요?

한국어, 영어, 일본어, 중국어 4개국어를 기본 지원합니다. 추가 언어(베트남어, 태국어 등)도 요청 시 대응 가능합니다. 각 언어별로 URL이 분리되어 SEO에도 유리합니다.

관리자 페이지는 어떤 기능이 있나요?

시술 물품 재고 관리(자동 차감, 부족 알림, 입고), 이벤트/프로모션 생성/수정, 팝업 이미지 관리, Analytics 대시보드 등을 코딩 없이 직접 관리할 수 있습니다.

워드프레스와 뭐가 다른가요?

Next.js 기반으로 제작되어 페이지 로딩 속도가 3~5배 빠르고, 구글 PageSpeed 점수 90점 이상을 보장합니다. 보안 취약점이 적고, SEO 최적화가 우수하며, 맞춤 디자인으로 병원만의 프리미엄 브랜드를 표현할 수 있습니다.

유지보수 비용은 얼마인가요?

월 유지보수는 합리적인 비용으로 제공되며, 콘텐츠 업데이트, 서버/보안 관리, 기술 지원을 포함합니다. 첫 상담 시 귀원에 맞는 맞춤 견적을 안내해 드립니다.
